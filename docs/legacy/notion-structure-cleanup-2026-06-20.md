# Notion 结构清理补充声明｜2026-06-20

## 范围

本声明只用于 GitHub 留痕，不要求 Notion 页面保留“我删了什么”“某页已退场”“置顶/历史记录”等自述性文字。

Notion 正文应保持可用、短、清楚：只留下当前如何进入、如何分流、如何判断。删除、退场、旧结构说明放在 GitHub / 沃壤侧。

## 已删除或不再作为活入口的 Notion 对象

- `公约数 · 出入场底谱`：不再作为公约数入口。
- `公约数 · 摩擦沉积床`：不再作为活数据库或验证入口。

后续遇到旧链接、旧索引、旧数据库残影：

1. 不在 Notion 正文写大段“已删除 / 已退场 / 曾经如何”的说明。
2. Notion 只保留当前入口与分流判准。
3. 如果需要解释原因、保留历史、避免未来 AI 误复活，写入 GitHub / 沃壤侧。

## 当前结构口径

- 公约数：运行层界碑；只管运行入口、L1、答案层、L2。
- 腐海：现场进场门；只管七判与直接分流。
- 泊坞 / 潮池 / 母液等旧缓冲层：不再承担主脊柱；若保留页面，只作为具体判断口或索引，不写成“退场纪念碑”。
- 破晓台：日用 Dashboard；不承担结构证明。
- 星盘：只维护当前拓扑，不记录清理过程。

## 操作原则

以后清理 Notion 结构时：

- 删掉迷惑人的自述性留痕。
- 保留真正能导航的判准。
- 已删除对象的补充声明放 GitHub。
- 不为了证明“做过清理”而污染页面第一屏。
