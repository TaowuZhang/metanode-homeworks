# 自动继续值守机

> **状态：已退役（2026-06-12）。** `watch.mjs`、`scripts/watch-awake.sh`、`notion-bridge.mjs` 已从仓库移除（谷裁决：完全停用）。设计图纸存于 `docs/legacy/notion-local-github-architecture-v1.md` 与 `docs/legacy/terminal-bridge-ops.md`。以下正文保留为历史运行记录。

## 当前状态
老 M1 作为 Notion 自动继续值守机；M5 作为主力工作机。同一时间只运行一个 watcher。

## 启动
在老电脑运行：`~/.local/bin/worang-watch`。看到 `watch.mjs ready` 表示上线。

## 值守条件
- 老电脑插电。
- Notion 目标对话框前台，窗口标题包含 `自动继续`。
- 输入框清空。
- Ghostty / Terminal 已获辅助功能、自动化权限。
- `NOTION_TOKEN` 存在 macOS Keychain，项名 `worang-watch-NOTION_TOKEN`。

## 自动继续实现
脚本把 `WATCH_AUTO_CONTINUE_TEXT` 写入剪贴板，通过 `Cmd+V` 粘贴，再用 `key code 36` 发送。这样绕开 AppleScript 直接 `keystroke "继续"` 对中文不可靠的问题。

## 限制
- 会短暂占用剪贴板；文本剪贴板会尝试恢复，非文本剪贴板不保证。
- 当前不主动拉回 Notion 前台。
- 老电脑只做值守，不做常规 Git 写入。

## 排障
- `Missing NOTION_TOKEN`：重新保存 Keychain token。
- `bad object refs/heads/main 2`：备份移走 iCloud 冲突 ref 后 fetch。
- `.git/index.lock`：确认无 Git 进程后删除残留 lock。
- 发出 `aa`：确认代码包含 `set the clipboard` 与 `keystroke "v" using command down`。
