# docs/sedimentation · workflow 沉淀产物层

`docs/sedimentation/` 只保存 workflow 产生的阶段性沉淀包，目前主要是 `notion-daily/`。

它不是 Notion 镜像，不是人读第二入口，也不负责保存长期判断。它的价值是：在 GitHub 侧留下可追溯、可 diff、可回访的机器产物。

## 放什么

- 自动化生成的 Notion 日沉淀包。
- 明确来自 workflow 的阶段性报告。
- 可用于审计、回放、定位失败的产物。

## 不放什么

- 手写的长期判断。
- Notion 页面全文镜像。
- 公约、触发语、X 的进场规则。
- `成为/`、`领域/`、`资源/` 应承接的内容。

## 维护口径

- 新增子目录前必须说明生成 workflow、产物用途、保留周期与删除条件。
- 产物可以厚；入口必须薄。
- 若某份沉淀开始被反复人读、复用或承重，应迁到对应三立基或 `docs/ops`，不能让本目录变成第二 Notion。
