# Web 第零期 Apple Design 复审 v0.1

时间：2026-05-09
对象：web/index.html + web/content/issue-zero.json / objects.json / scenes.json
来源：Apple Design 导入资料，重点参考 Continuity、Spatial layout、Designing for visionOS、Liquid Glass、Typography。
用途：不是把网页做成 Apple 风，而是用 Apple 的空间、连续性、层级与可读性原则审当前第零期页面。

## 复审结论

当前第零期已经被 NNGroup 校正为清楚、可预期、可读。Apple Design 这一轮要补的不是更多信息，而是现场感：

- 场位切换应像同一现场中的观看位置变化，而不是普通 tab。
- 物件靠近解释应像把物件拿近，而不是弹窗。
- 内容层、控制层、证据层要分清楚。
- 不能被 Liquid Glass 诱惑成全页面材质化。
- 文字仍是第一界面，不能为了深度牺牲可读性。

一句话：第零期不需要更炫，需要更像一个可以进入的现场。

## 1 Continuity：场位切换应保持同一任务流

Apple Continuity 的要点是：用户切换设备、窗口或尺寸时，不应该感觉重新开始，而应该延续同一个任务流。

迁移到第零期：

- 四个场位不是四个页面，而是同一批物件的四种观看位置。
- 切换场位时，标题、opening、场位说明、卡片结构都应保持稳定。
- 物件重排可以发生，但用户不能丢失“我还在第零期现场里”的感觉。
- 场位按钮不是导航菜单，而是观看位置选择器。

当前状态：
- 已有统一卡片结构和场位说明。
- 切换后不会离开页面。
- 但视觉上还像普通 tab，缺少“同一现场内换位”的感觉。

最小建议：
- 场位切换区做成轻微 shelf / 工作台边缘，而不是普通按钮行。
- 当前场位说明区作为“当前位置”固定在按钮下方。
- 不做页面跳转，不做大幅动效。

## 2 Spatial layout：重要内容在中心，避免窗口过多

Apple Spatial layout 强调：重要内容应放在视野中心；避免过多窗口；用深度传递层次，但不要让深度伤害文字可读性。

迁移到第零期：

- 当前每个场位 3–4 张卡是合适的，不应继续扩成很多窗口。
- 卡片网格应保持松动空间，避免压迫。
- 场位说明是当前上下文，应在卡片之前。
- 近看解释不应弹成遮挡全局的 modal。

当前状态：
- 数量可控。
- 网格和 details 都比较克制。
- 但卡片 hover/focus 没有“可拿近”的提示。

最小建议：
- 给卡片 hover/focus 增加轻微 lift。
- details 展开时该卡片略微提前，其他卡片不消失。
- 不新增浮窗。

## 3 “拿近”而不是弹窗

Apple visionOS 的关键启发不是“做 3D”，而是让用户在空间中保持方向感和舒适感。标准任务使用窗口化体验，关键时刻才提升沉浸级别。

迁移到第零期：

- 物件靠近解释应留在卡片内部。
- 展开 details 时，像把卡片拿近一点，而不是打断现场。
- 用户应始终能看见其他物件和场位按钮。

当前状态：
- details 是正确的最小实现。
- 没有 modal，方向正确。

最小建议：
- details[open] 时增加边界、阴影、轻微上移。
- summary 文案保持“靠近解释”，不改成“详情”。
- 不让展开态压倒全部页面。

## 4 Liquid Glass：控制层可以浮，内容层要清

Apple Liquid Glass 的关键不是玻璃效果，而是层级纪律：它适合悬浮于内容之上的导航层或控制层，不适合铺满内容层；避免 glass-on-glass；避免控制层和内容层抢焦点。

迁移到第零期：

- 场位切换条可以有轻微悬浮感。
- 当前场位说明可以像贴在桌上的便签。
- 物件卡仍应保持纸感 / 内容层清晰。
- 证据层不要再叠玻璃。

当前状态：
- 页面现在偏纸感，安全。
- 还没有过度材质化风险。

最小建议：
- 只给 tabs / scene-note 很轻的浮层感。
- 不给所有卡片加毛玻璃。
- 不做 glass-on-glass。
- 不牺牲文字对比度。

## 5 Typography：文字仍是第一界面

Apple Typography 强调：排版用于可读、层级、重点和风格；带深度的文字更难读；应优先保持二维文字、对比和响应性。

迁移到第零期：

- 远看、中看、近看证据是页面核心。
- 动效和空间只能服务文字，不应抢文字。
- 字体层级已经基本成立，但仍应保持克制。

当前状态：
- 文案已完成 copy pass。
- 标题、opening、场位说明、卡片文案层级清楚。
- details 内近看信息偏密，但可接受。

最小建议：
- 不给文字加 3D / 倾斜 / 深度。
- 保持行高和段落留白。
- details 内证据继续用小号但高对比文本。

## 6 对当前页面的最小补丁建议

只改 CSS / 微交互，不改数据结构，不加新功能。

建议落地：

1. 场位按钮区增加 shelf 感：
   - 轻微 sticky 或半浮层；
   - 背景仍保持温暖纸感；
   - 当前按钮状态更明确。

2. scene-note 增加便签感：
   - 保持清晰背景；
   - 加轻微阴影或左边线；
   - 不做玻璃。

3. 卡片可拿近：
   - hover/focus 轻微上移；
   - 阴影稍强；
   - transition 控制在 160–220ms。

4. details 展开态：
   - 卡片边界稍微强调；
   - details 区域不脱离卡片；
   - 不弹 modal。

5. 保持文字二维：
   - 不做旋转；
   - 不做 3D；
   - 不做低对比透明文字。

## 不做什么

- 不做 Apple 风拟态。
- 不做整页 Liquid Glass。
- 不新增动画系统。
- 不增加场位。
- 不增加物件。
- 不把 details 改成 modal。
- 不牺牲文字可读性。

## 复审后的原则

Apple 这一轮给第零期的不是视觉皮肤，而是空间纪律：

> 控制层轻轻浮起，内容层保持清楚，证据层在物件内部被拿近；人在切换场位时，始终知道自己还在同一个现场里。
