# 成为认知—嫁接 UUID 链接清理 2026-06-07

## 范围

本轮只处理 `成为/嫁接/` 中已经能被目录实证确认的 `蒸馏自` 链接。

不做：

- 不全仓扫 UUID。
- 不重写认知库或嫁接库正文。
- 不补造缺失对象。
- 不碰 `成为/项目`、`成为/色散`、论文审阅项目等更深层历史导出链。

## 判断

`成为/认知/` 当前已有干净文件名，例如：

- `思.md`
- `推理.md`
- `识.md`
- `归类.md`
- `想.md`
- `判.md`
- `记.md`
- `解.md`
- `言.md`

因此，`成为/嫁接/` 里指向这些认知页的旧 Notion 导出链接可以从：

```md
../%E8%AE%A4%E7%9F%A5/某页 <uuid>.md
```

改为：

```md
../认知/某页.md
```
