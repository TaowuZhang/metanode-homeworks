# 色散—项目 UUID 链接清理 2026-06-07

## 范围

本轮只处理 `成为/色散/` 中已经能被目录实证确认的 `关联项目` 链接。

它承接前两刀认知—嫁接双向链清理，但进入更深一层：从色散事件页指向项目页。

不做：

- 不全仓扫 UUID。
- 不重写色散页正文。
- 不补造缺失对象。
- 不处理项目页内部子页引用。
- 不碰论文审阅项目内部阶段页。

## 判断

`成为/项目/` 当前已有干净文件名，例如：

- `推·自媒体.md`
- `学·DSA.md`
- `建·技术栈路线.md`
- `研·猜意.md`
- `建·AI实录.md`
- `建·技术雷达.md`
- `研·行业招聘.md`
- `推·WQB量化.md`
- `建·个人页面.md`
- `学·CS101.md`
- `学·冲刺安全.md`

因此，`成为/色散/` 中指向这些项目页的旧 Notion 导出链接可以从：

```md
../%E9%A1%B9%E7%9B%AE/某项目 <uuid>.md
```

改为：

```md
../项目/某项目.md
```
