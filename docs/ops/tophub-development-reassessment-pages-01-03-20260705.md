## 第 1 页｜12 个节点

### 1. 安全客｜最新

**结论：不常驻；安全任务时按需。**

样本同时包含：

- NGINX、Splunk、勒索软件和供应链漏洞；
- AI 安全网关、Agent 安全与提示注入；
- 厂商新品、渠道招募、会议宣传和软文。

问题：

- 技术分析、新闻转载与商业宣传混排；
- 阅读量数字异常高，不能作为质量信号；
- 与现有 `先知社区｜精华推荐`、darkreading、FreeBuf 和具体 CVE 检索重叠。

`先知社区｜精华推荐`已经承担中文应用安全和 Agent 安全的高筛选入口，因此不再叠加安全客。

### 2. InfoQ中国｜7天热点

**结论：B 级按需，不进入持续候选。**

有价值的部分：

- Agent 规模化落地；
- 热补丁自动生成；
- SGLang Tracing；
- Lambda MicroVM；
- 工程分工和架构变化。

问题：

- 新闻、厂商文章和工程实践混排；
- 标题冲突化明显；
- 与 InfoQ 国际站、现有科技媒体及 AI 专题来源重复。

需要研究某一工程事件时可以打开，不形成每周阅读责任。

### 3. GitHub｜Trending Monthly

**结论：不订阅；按需查看。**

月榜比日榜稳定，但仍由短期 Star、社交传播和 AI 热点驱动。当前样本中大量为：

- MCP；
- Skill；
- Agent；
- 系统提示词泄露；
- AI 工作流和快速增长项目。

它不能回答：

- 项目是否可靠；
- 是否仍在维护；
- 是否适合用户当前技术栈；
- 安全与许可证情况；
- 是否只是营销或短期爆发。

现有 `HelloGitHub｜月刊`已经为开源项目发现提供了人工筛选和中文说明；真实项目需求则应直接搜索 GitHub，而不是持续消费 Trending。

### 4. 掘金｜后端本周最热

**结论：按任务检索，不常驻。**

FastAPI、Go、数据库、Java、微服务、图像服务和 AI Coding 混在一起。偶尔能发现有用实战，但标题和热度无法稳定区分深度、转载、面经和营销。

当用户正在学习 Go、排查具体后端问题时可搜索对应文章，不建立宽泛周榜。

### 5. 新趣集｜今天新发现

**结论：与 Product Hunt 高度重复，不订阅。**

本页的 Termi Protocol、ChecklistFox、Vox、Glaze、Retrace、Context.dev、Macuse 等项目与同页 Product Hunt 大量重合，只是中文化重新包装。

它不提供独立验证、长期使用反馈或安全判断。

### 6. FreeBuf｜最新

**结论：B+ 安全任务型入口。**

优点：

- 有资产发现、IKEv2、CodeQL、反序列化、EDR、供应链和勒索数据分析；
- 能看到中文安全社区的实战材料；
- 当前与 Codex、CodeQL、Agent 安全和威胁情报存在直接交叉。

问题：

- 早报、厂商白皮书、教程、聚合情报和实战文章混排；
- 质量波动明显；
- 频率过高。

路由：研究具体漏洞、供应链、渗透链路或国内安全实践时调用；不与先知和 darkreading 同时常驻。

### 7. Product Hunt｜今日新产品

**结论：不订阅；产品发现时按需。**

当前 50 个产品中大量是未经验证的 AI 包装、MCP、小工具和营销产品。日榜适合漫游，但不适合作为编程知识或可信产品判断入口。

与新趣集重复时优先看原始 Product Hunt 条目，而不是双重订阅。

### 8. 博客园｜48小时阅读排行

**结论：B 级按需。**

优点是仍能看到 C#、Linux 驱动、Rust、RAG、模型部署和个人工程记录。

问题是：

- 热门榜容易被 AI Coding 与教程标题占据；
- 文章技术深度差异大；
- 很多内容只有在使用对应语言或框架时才有价值。

保留为中文具体问题搜索入口，不订阅排行。

### 9. 白鲸出海｜今日热文

**结论：错位节点，不属于程序编程。**

内容是广告、品牌、游戏市场、短剧、跨境电商和欧盟税务。其角色已由数据与结构中的 `36氪出海｜热门推荐`及其他商业来源覆盖。

### 10. JavaScript Weekly｜最新期刊

**结论：A2 条件候选。**

当前一期包括：

- Flow 与 TypeScript；
- npm 默认禁用安装脚本；
- TypeScript 类型检查性能；
- AI 测试有效性；
- Hermes Bytecode；
- ESLint、Zod、数据库与 CSS。

优势：

- 周频而非日频；
- 编辑筛选清楚；
- 能同时覆盖语言、生态、安全与性能；
- 比掘金前端热榜更接近原始技术变化。

限制：

- 用户当前主线不是 JavaScript / TypeScript；
- 若没有活跃 Web 或 Node 项目，会制造与任务无关的未读。

暂时进入后续比较池。只有最终目录缺少高质量语言生态周刊，且用户重新进入 Web/Node 项目时，才考虑 Folo 或 TopHub。

### 11. 安全脉搏｜最新

**结论：B+ 中文漏洞分析任务源。**

优点：

- 代码审计、路由器漏洞、Rust 逆向、pocsuite3、注入和 RCE 分析；
- 偏技术复现，商业新闻少于安全客。

问题：

- 不少样本是旧 CVE 复现；
- 更新时效和质量不稳定；
- 更适合作为案例库而非新闻流。

研究具体漏洞、代码审计和渗透技巧时调用。

### 12. 掘金｜全站最新

**结论：明确排除常驻。**

“最新”没有任何编辑筛选，题目从 OA、BFM、Android/iOS 到 MCP、RAG、JavaScript、Python 混排。它是内容库存入口，不是注意力入口。

## 第 2 页｜12 个节点

### 1. Solidot｜热门文章

**结论：不新增。**

它是综合科技与科学新闻站，而不是开发源。当前内容涉及 AI 专利、阿里、Steam Machine、农药、NASA、大脑、极端气候和天文。

现有科技雷达与科学来源已经覆盖其角色，加入会增加重复。

### 2. 咖啡日报｜今日推荐

**结论：排除。**

PMCAFF 社区帖子、求项目、岗位感受和产品讨论为主，内容量少且样本陈旧，不属于编程信息源。

### 3. 掘金｜iOS本周最热

**结论：平台任务型入口。**

缓存、弱网、OOM、Live Activity、GCD 和 Swift 周报具有实际价值；但用户当前没有活跃 iOS 项目。需要 iOS/macOS 开发时再按主题查阅。

### 4. 掘金｜阅读本周最热

**结论：排除常驻。**

栏目主题不稳定，当前几乎被 AI Agent、Harness、MCP、RAG 和入门算法占据。它不是稳定的技术角色，只是另一种文章热度切片。

### 5. Hacker News｜最新榜单

**结论：高价值、但坚持按需，不订阅。**

HN 能发现软件工程、数据库、语言、开源、科学、社会和个人写作，但“最新”样本同时包含：

- 密码学；
- 冥想；
- 电池；
- 生物学；
- 天文；
- 艺术；
- 旧文章；
- 新工具；
- AI Coding。

问题不是内容差，而是频率和跨度过大。持续订阅会形成永远清不完的技术雷达。需要观察开发者舆论、某一工具发布或寻找不同观点时打开即可。

### 6. 掘金｜阅读热门

**结论：排除常驻。**

职场、收入、副业、健康、AI 视频、React、Bun 和工程文章混排。它更接近程序员生活话题热榜，而不是编程来源。

### 7. SocialBeta｜热榜

**结论：错位节点。**

营销案例、广告创意、招聘和品牌内容，不属于开发。当前系统无需从开发目录重复引入。

### 8. TesterHome｜七日最热

**结论：A2 强候选，进入最终比较池。**

当前主题集中于：

- AI 使用原则；
- 非开发背景测试人员能否借 AI 开发平台；
- AI 辅助影响分析和测试用例生成；
- Harness 下的 API 验收测试；
- Skill 的选择、生产化与返工风险；
- Agent 测试 Workflow；
- 企业级测试设计。

它的独特价值：

- 不是单纯报道模型发布；
- 从测试、验收、失败和质量保证看 AI Coding；
- 与本地 Codex、GitHub PR、代码审查和“代理完成不等于任务完成”直接相关；
- 提供中文测试社区的第一手实践和争论。

风险：

- 社区讨论质量不一；
- 热门话题当前可能因 AI 过度集中；
- 需要观察是否长期有测试工程内容，而不是阶段性 Agent 热潮。

暂定路由：优先考虑 Folo 观察期；也可能在完整 290 节点比较后成为科技雷达的低频社区节点。现在不执行。

### 9. 人人都是产品经理｜天天问热门问答

**结论：排除。**

问答过于基础且主题宽泛，不是编程来源，也无法补足现有产品和社区入口。

### 10. 掘金｜前端本周最热

**结论：任务型入口，不常驻。**

React、性能、Next.js、Bun、Compose、路由和 AI Coding 混合。前端项目出现时可检索；持续订阅会与 JavaScript Weekly、官方框架博客和 GitHub 重复。

### 11. 掘金｜Android本周最热

**结论：平台任务型入口。**

Amper、Kotlin Toolchain、Android 架构、Compose、Room、Navigation 和性能分析对 Android 项目有用。用户当前关注 vivo/Android 主要是产品和使用层面，不足以建立开发周榜。

### 12. SegmentFault｜每周精选

**结论：B 级按需。**

低频筛选优于“最新”，但内容仍是多语言、多框架的问答与教程拼盘，包含大量基础排错。适合搜索具体问题，不适合作为长期技术方向来源。

## 第 3 页｜12 个节点

### 1. GitHub｜Trending Today

**结论：不订阅。**

日榜波动最大，当前明显被 Codex、Agent、MCP、Skill、系统提示词和 AI 工具占据。它反映短期传播速度，不等于软件质量或长期价值。

### 2. CSDN｜今日头条热点

**结论：明确排除。**

样本混合旧闻、会议宣传、重复标题、夸张收益、未经验证传言、课程广告和公司新闻；多个条目仍停留在 2025 年甚至更早的事件。

该节点不能承担当前开发事实源。

### 3. 人人都是产品经理｜日榜

**结论：错位且过量，不订阅。**

内容以产品、商业化、AI 行业、运营、课程、工具测评和营销为主。即使有 Agent 安全、知识图谱和多智能体文章，也不能因此把整个百条日榜变成开发入口。

### 4. 掘金｜全站本周最热

**结论：不订阅。**

样本高度集中在 Agent、模型、AI Coding 与招聘，且存在重复文章。周榜仍没有解决来源验证和主题漂移问题。

### 5. 人人都是产品经理｜最新

**结论：排除。**

比日榜更缺少筛选，属于产品内容库存入口。

### 6. 开源中国｜热门资讯

**结论：B 级按需，不进入当前候选。**

优点：

- 软件版本发布；
- 开源项目动态；
- PHP、gRPC、Memcached 等具体更新；
- 中文开源生态消息。

问题：

- 版本公告、模型测评、传言、公司新闻和安全事件混排；
- “热门”会被 AI 模型与争议标题主导；
- 真实依赖更新更适合官方 release、GitHub 和包管理器。

### 7. 咖啡日报｜PMCAFF精选

**结论：排除。**

长期产品经理教程、PRD、会员、电商营销和沟通方法论为主，且样本明显是历史高阅读文章，不属于当前开发雷达。

### 8. 掘金｜工具资源本周最热

**结论：不常驻。**

AI Coding 工作台、终端美化、MCP、CLAUDE.md、Trae、WebDAV 和系统清理混在一起。能偶尔发现工具，但缺少安全、维护和真实使用验证。

开源工具发现继续由 HelloGitHub、GitHub 精确检索和真实任务承担。

### 9. GitHub｜Trending Weekly

**结论：不订阅。**

比日榜稍稳定，但和月榜同样受到短期 Star 与 AI 浪潮影响。三个 GitHub Trending 周期不需要三选一，而是全部退回按需。

### 10. 湾区日报｜最新期刊

**结论：内容有价值，但节点疑似历史库存；保留为旧文阅读库。**

样本中有很多与用户高度契合的主题：

- finished software；
- File over app；
- 开源维护者；
- 写作作为思考；
- 小而长期的软件生意；
- 系统重写；
- 内部工具；
- 软件消亡和数据可迁移；
- 技术工作与人的经验。

但当前列表大量引用多年前的文章和事件，无法证明这个 TopHub 节点仍是稳定更新的“最新期刊”。

因此：

- 不作为新闻或开发雷达订阅；
- 可作为慢读与软件文化的历史选文库；
- 后续若目录里出现仍活跃、同类但更新稳定的来源，再进行替代比较。

### 11. 掘金｜人工智能本周最热

**结论：已被 AI 目录结论覆盖，排除。**

它重复 Agent 模型比较、RAG、Skill、Harness 和 GitHub 热门项目，不能因为位于开发目录就重新打开已经闭环的 AI 热榜判断。

### 12. HelloGitHub｜月刊

**结论：已订阅，保持。**

当前真实位置：

- 科技雷达第 11 个节点；
- 全局第 29 位。

它承担：

- 中文开源项目发现；
- 月频低压力筛选；
- 项目介绍而不是原始 Star 排行。

本页验证了它相对于 GitHub Trending Today / Weekly / Monthly 的必要性。无需新增、移动或替换。
