### 2. Eugene Yan

**角色：生产系统、Evals、搜索推荐与团队机制。**

保留原因：

它比一般“AI 工程教程”更接近如何长期构建、验证和维护系统。

### 3. AI as Normal Technology

**角色：可靠性、制度条件与反神话判断。**

保留原因：

- 讨论 Agent 可靠性与开放世界评测；
- 核验“Agent 建成操作系统”“AI 替代工程师”等宏大说法；
- 把 AI 放回组织、劳动、法律、科学和制度；
- 能抵消厂商叙事、AGI 里程碑叙事和 x-risk 单一路线。

边界：

- “正常技术”同样只是一个分析框架；
- 不把它提升为新的默认裁决；
- 与工程证据和其他社会视角并读。

负责：

- Agent 攻防；
- 缺陷协调披露；
- 评测效率。

这是“AI 评测与 Agent 可靠性”主题的首选研究入口，但不订阅整个机构动态。

### SemiAnalysis

负责：

- GPU、HBM、晶圆；
- 数据中心功率和可靠性；
- 训练、推理与 TCO；
- AI 资本开支和供应链。

不可替代，但付费墙、篇幅和专业负担较高。研究算力经济时访问，不成为普通阅读流。

### Interconnects

负责：

- 开放模型；
- 后训练；
- 模型生态；
- 中美 AI 研究与产业结构。

质量高，但与 Last Week in AI、官方模型来源和当前工程候选存在覆盖。保留在沃壤，不进入这一轮 Folo 四个名额。

### EleutherAI Blog

负责：

- Reward Hacking；
- 机制可解释性；
- 开放模型安全；
- 训练数据、RLHF 和模型透明度。

作为研究入口使用，不要求持续阅读。

### BAIR Blog

负责具体研究方向：World Model、推理、Prompt Injection、视觉、机器人与生成模型。按项目调用。

### Hugging Face Blog

官方工程和开放生态价值高，但更新量大、产品范围广。需要模型、数据集、训练、推理或具体工具时访问，不建立全量未读队列。

### Nature Machine Learning、JMLR、arXiv cs.CL / cs.CV / cs.LG

只按：

- 具体问题；
- 关键词；
- 作者；
- 论文引用链；
- 项目需要。

不订阅完整分类。
