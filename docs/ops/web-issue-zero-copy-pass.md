# Web 第零期 Copy Pass｜从研究语气到场刊语气

时间：2026-05-09
对象：web/content/issue-zero.json / objects.json / scenes.json
状态：改稿前审稿 v0.1

## 目标

降低术语负荷，增强信息气味，让外部访客不用先理解整套方法，也能知道自己正在进入什么、能点什么、靠近后会得到什么。

不改结构，不加功能，不做视觉大改。先修文案气味。

## 当前问题

1. 场位名有气质，但仍偏内部：本期场刊、工作室、证据场、幕后施工需要普通话解释。
2. 物件远看有些像隐喻，有些像内部标记；需要更像「可闻到的线索」。
3. 物件中看有些像方法定义；需要只说明它在第零期里做什么。
4. 近看结构已经成立，不要上移抢占远看层。
5. “物理语法 / 显式场位 / 复审 / schema”等词可保留在幕后，不宜作为访客入口文案。

## 改稿原则

- 远看：像气味，不像定义；一句话让人愿意靠近。
- 中看：只解释一件事；不要同时讲方法、来源和价值。
- 场位说明：告诉访客点它会看到什么。
- 场位问题：用一句问题制造进入动作。
- 近看：保留证据结构，不做情绪营销。
- 少用元语言，多用现场语言。
- 不把第零期写成“成果展示”，而写成“正在生成”。

## 字段级建议

### issue.opening

当前：
这不是正式发布，而是网站生成前的试运行：入口、物件、来路和护栏先出现，视觉和动效后到。

建议：
这不是正式发布，而是一次开场前的试运行：先把入口、物件、来路和护栏摆出来，再让视觉和动效慢慢跟上。

理由：更像场刊开场，少一点工程报告感。

### scenes.programme.description

当前：
从这一轮发生了什么进入：先看第零期如何把网站生成过程摆出来。

建议：
先从这一轮发生了什么进入：哪些东西被摆上桌，哪些判断开始成形。

### scenes.studio.description

当前：
从材料关系观看：文档、护栏、资料和终端桥如何彼此靠近。

建议：
像走进一间还在工作的房间：文档、护栏、资料和终端桥都还摆在桌上。

### scenes.evidence.description

当前：
从痕迹和反默认判断观看：每个结论凭什么成立。

建议：
不急着相信结论，先看它留下了什么痕迹，又反对了什么默认想象。

### scenes.backstage.description

当前：
从未完成处观看：哪些东西还在下载、导入、补审和等待。

建议：
看那些还没完成的部分：下载、导入、补审、等待，也都是第零期的一部分。

## 物件中看改稿方向

中看不追求诗意，负责说清它在第零期的作用：
- 三意象：说明三种组织动作。
- 反猜意图护栏：说明它阻止系统猜访客。
- 方法文档：说明它把资料压成约束。
- brief：说明它定义第零期。
- 回顾：说明它记录否定和张力。
- UIUX 导入：说明资料被分配成护栏、刹车、手感。
- 终端桥：说明它让讨论变成文件和 commit。
- 缺席位：说明未完成也被纳入现场。
