## 为什么选择周报，而不是热门或技术节点

1. **周频适合社区信息。** V2EX 的价值不是每天追新闻，而是观察开发者、独立创作者和技术使用者一周内真正持续讨论了什么。
2. **同时保留主题与高赞回复。** 周报不只是标题榜，能够减少只凭标题判断的失真。
3. **降低推广污染。** 当前最热、今日热议、技术、程序员和首页最新均出现大量 AI 中转、账号渠道、拼车、封号与灰色服务讨论；V2EX 自身版块也在集中抱怨热榜被推广和中转站占据。
4. **不重复现有科技媒体。** 科技雷达已经负责新闻、产品变化、科学和安全。V2EX 周报补的是具体使用者的经验、故障、选择和工作方式。
5. **符合 TopHub 的职责。** 它是公共技术社区的一周天气，而不是需要逐条清空的长期订阅。

## 其他节点的处理

### 不订阅的高频总榜

- 最热主题
- 最新主题
- 首页最新
- 今日热议

原因：生活、技术、推广、账号渠道和情绪话题混杂；更新过快，会形成持续未读。

### 不订阅的技术聚合节点

- 技术
- 程序员
- 互联网
- 问与答

这些节点确实包含真实故障、工具经验和工程讨论，但当前页面同时充斥模型比较、账号封禁、中转站、低价 API 与推广。具体技术问题应按需检索，而不是常驻。

### 高价值按需节点

以下节点在对应任务中很有用，但不需要日常订阅：

- `Apple`：Mac、iPhone、Apple ID、区域账号、系统升级与配件问题；
- `Android`：系统、Root、Termux、Google 框架、eSIM 与应用兼容；
- `硬件`：装机、显示器、存储、扩展坞与故障排查；
- `DNS`：DoH、DoT、DoQ、ECS、Fake-IP 与运营商解析问题；
- `信用卡`：香港银行卡、虚拟卡、跨境支付与订阅支付经验，但必须重新核对银行官方政策；
- `汽车`：购车、续航、保险和真实用车经验；
- `Blog`：寻找仍在更新的独立博客时用作发现入口。

### 产品发现节点

- 创意
- 分享创造
- 分享发现

它们能发现小工具、独立产品和开源项目，但自荐、推广、AI 工具站与重复内容密度很高。两个“分享创造”卡片内容重复，不应双订阅。

较强的产品或经验帖通常会进入周报，因此不再额外保留这些高频节点。

### 交易节点

`交易`包含账号拼车、会员车位、二手设备和礼品卡等，风险与时效性都高，不进入信息系统。

能够看到 AI、工作、价值与生活的自发表达，但质量跨度很大、标题判断成本高。用户已有慢读与思想来源，不需要将碎片随想常驻。
