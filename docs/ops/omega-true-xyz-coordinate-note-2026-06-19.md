## 第四轴：控护 ↔ 自主承异

这条轴已定名为「控护 ↔ 自主承异」。它抓住两端在 Schwartz 圆环上的真实贴靠：一端偏向权力 + 安全，另一端偏向自我导向 + 普适主义。

**控护**：连接权力与安全。它显影系统面对威胁、不确定性、资源暴露、位置脆弱或秩序松动时，是否倾向通过控制、占有、规则、防护、边界和威胁管理来稳定世界。

**自主承异**：连接自我导向与普适主义。它显影系统面对差异、陌生性和不可同化对象时，是否倾向通过独立判断、理解、宽容、普遍承认和开放视野来容纳世界。

因此第四轴的问题不是「个人 vs 他人」，也不是「自私 vs 利他」，而是：

> 面对不确定、差异、威胁或陌生世界时，是用控制与防护来稳定它，还是用自主判断与普遍承认来容纳它？

## 第三轴：未来趋向 ↔ 沉积来处

这条轴是时间相位 / Git 祖宗法的入口：一端显示未发生的牵引、试探、分叉和可能性；另一端显示已经沉积的来处、历史、commit、回滚痕迹和可寻址祖宗。它不替代 Schwartz 的传统/刺激，而是在 Ω 场里显影「力量从哪里来、往哪里拉」。
