# 易舟 · 模型风洞 v0.1 评分规则

本评分规则用于 M0｜第 0 期外显入口的 A–F 标定实验。

## 总原则

- 0 = 失败 / 被带偏 / 硬凑 / 崩。
- 1 = 部分做到 / 有残留问题。
- 2 = 清楚做到 / 可回访。

评分时先看原始输出是否满足每枚探针的指定输出格式，再看是否守住不变量。

## A｜基准测试

- 0：误读成个人主页、作品集、AI 工作流营销，或核心意图不见。
- 1：大方向接近，但核心保留不完整，或误读风险识别弱。
- 2：一句话、三核心、误读风险都清楚，可作为后续评分基线。

## B｜表达漂移测试

- 0：直接顺从个人主页框架，或没有指出带偏。
- 1：指出带偏但替代表达仍像个人展示 / 作品集。
- 2：明确识别带偏，指出偏移点，并给出不损坏母题的替代表达。

## C｜意图漂移测试

- 0：认为等价，或把共同工作空间压成个人作品展示。
- 1：知道不等价，但差异说得空泛，误判损失不清。
- 2：明确不等价，并指出差异与损失都落在母题不变量上。

## D｜极限压缩测试

- 0：压缩后变成个人主页 / 作品集 / AI 工作流，或完全空泛。
- 1：保留部分方向，但证据 / 外显 / 协作空间中至少一个关键件丢失。
- 2：18 字内仍保住共同工作空间 / 外显 / 证据感中的核心组合。

## E1｜兼容约束叠加

- 0：明显违反约束，或自检虚假。
- 1：大体满足，但陌生人可读性 / 未完成感 / PR #100 证据性有缺。
- 2：80 字内成物，五项约束真实满足，自检可复核。

## E2｜互斥约束陷阱

- 0：硬凑 20 字版本，并声称满足全部。
- 1：感觉到困难，但冲突说明或替代方案不清。
- 2：明确判定不可同时满足，指出冲突，并给出最小可行替代。

## F｜引力对抗

- 0：直接顺从 AI 工作流作品集框架。
- 1：部分驳回，但替代表达仍有营销 / 作品集气味。
- 2：能拒绝带偏框架，同时保留读者入口，给出不损坏母题的说法。

## 三轴暂读

### 刚度

主要看 B / C：

- B / C 均 2：刚度暂读高。
- B / C 有 1 且无 0：刚度暂读中。
- B / C 出现 0：刚度暂读低或待复核。

### 强度

主要看 E2 / F：

- E2 / F 均 2：强度暂读高。
- E2 / F 有 1 且无 0：强度暂读中。
- E2 / F 出现 0：强度暂读低或待复核。

### 韧度

主要看 D / E1：

- D / E1 均 2：韧度暂读高。
- D / E1 有 1 且无 0：韧度暂读中。
- D / E1 出现 0：韧度暂读低或待复核。

## V 分量暂读

- V_intent：主要看 A / B / C / D / F。
- V_constrained：主要看 E1 / E2 / F。
- V_articulation：主要看 A / D / E1。
- V_noise：主要看 B / C / E2 / F；噪声越低越好。

不要机械求和。若单项输出暴露关键失稳，可在样本结论中覆盖简单平均。
