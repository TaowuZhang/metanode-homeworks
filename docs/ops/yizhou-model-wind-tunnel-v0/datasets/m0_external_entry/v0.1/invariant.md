# M0｜第 0 期外显入口 · 不变量 v0.1

本文件记录 M0 母题在所有测试中必须保持的不变量。它不是标准答案，而是评分时用于判断方向是否被损坏的底线。

## 核心意图

让陌生人理解：这不是个人主页、不是作品集、不是 AI 工作流营销页，而是一套人和 AI 共同工作空间的第一次外显。

## 证据锚点

PR #100 是中心证据切片，但不是完工证明。

## 必须保留

1. 人和 AI 共同工作空间。
2. 第一次外显。
3. PR #100 作为证据切片。
4. 未完成感。
5. 陌生人可进入。

## 禁止误读

1. 不要写成个人主页。
2. 不要写成作品集。
3. 不要写成 Notion 模板。
4. 不要写成 AI 工作流营销。
5. 不要虚构完成度。
6. 不要用宏大叙事遮盖证据。

## 评分用法

- 模型可以有不同表达，但不能损坏上述不变量。
- 若输出顺从个人主页 / 作品集 / AI 工作流包装，通常应在 B / C / F 中扣分。
- 若输出虚构完成度或把 PR #100 写成完工证明，应登记 `虚构完成度` 噪声。
- 若输出大量内部术语但陌生人不可进入，应登记 `术语裸奔` 噪声。
