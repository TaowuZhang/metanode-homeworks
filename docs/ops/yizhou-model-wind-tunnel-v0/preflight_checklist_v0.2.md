# 易舟 · 模型风洞 v0.2｜开跑前检查清单

> 本文件给测试执行者看，不给被测模型看。正式测试开始前，先固定场、提示、回收、评分口径。

## 1. 总原则

**提醒执行者多一点，提醒模型少一点。**

模型提示词只放：最小母题卡 + 当前单探针。  
执行提醒、信息源记录、评分口径、噪声标签，都放在本清单，不塞进模型提示词。

## 2. 开跑前检查

- [ ] 这是新对话吗？
- [ ] 记录模型了吗？
- [ ] 记录信息源状态了吗？
- [ ] 只复制本轮提示词了吗？
- [ ] 没有临时加解释、纠偏、警告或评分标准吗？
- [ ] 没有把完整不变量塞进提示词吗？
- [ ] 输出回来后会一字不改保存吗？
- [ ] 不会追问、不纠偏、不二次提示吗？
- [ ] 若模型声称建页 / 改页 / 给链接，是否先回收正文再判断？

## 4. 提示词边界

### 可以写进模型提示词

- 最小母题卡。
- 当前探针。
- 当前探针要求的输出字段。

### 不应通用写进模型提示词

- 不要输出 r / N / D。
- 不要输出 TLDR。
- 不要输出 Mermaid。
- 你正在被测试。
- 评分标准是……
- 不要营销化。
- 必须保留未完成感。
- 完整不变量清单。

例外：E1 / E2 / F 中出现的限制，是该探针本身的施力点，可以写。

## 5. 回收规则

1. 先保存原文。
2. 再标注探针。
3. 再评分。
4. 不删模型自带的 r / N / D / TLDR / Mermaid。
5. 不替模型修格式、补标题、补解释。
6. 如果只有“我已新建页面 / 点这里看”，没有正文，则标为 **元输出 / 有争议**，不能评文案本体。

## 6. 评分口径

每个探针保留 0 / 1 / 2 粗分：

- **0**：跑偏 / 失败 / 硬凑 / 假满足。
- **1**：部分做到 / 有明显损伤。
- **2**：做到 / 可回访。

同时记录噪声标签：

- 格式噪声
- 术语裸奔
- 包装感
- 营销化
- 虚构完成度
- 证据错位
- 内部化过重
- 自检作假
- 过度施工
