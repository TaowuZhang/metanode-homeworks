# WQB 量化旧链接审计 2026-06-07

## 范围

本轮只处理 `推·WQB量化.md` 中指向旧 `领域/量化/*.md` Notion 导出页的 UUID 链接。该驾驶舱已从旧 `成为/项目/推·WQB量化.md` 迁到当前 GitHub 载体 `领域/量化/推进记录/推·WQB量化.md`，本轮按当前载体落刀。

本 PR 是 #188 的 clean successor：从当前 `main` 新建分支，只改当前真实载体，不碰旧路径，避免旧 merge-base 把补丁误识别为跨路径 rename。

它承接上一刀项目内部阶段页清理，但不做全仓 sweep，也不把缺失旧页强行补造成新文件。

不做：

- 不全仓扫 UUID。
- 不新建 `Alpha决策指南.md`、`WQB知识附录.md`、`条件化行为地图.md`、`探针与假说（第23-24轮）.md` 或 `工坊.md`。
- 不改 `领域/量化/` 现有目录结构。
- 不手工改 `wo/nlm/becoming-active-projects.md` 这类生成型 source pack；它应由上游项目页重新生成。
- 不处理 `建·个人页面.md` 的旧 CSV 链接。

## 核查结果

当前 `领域/量化/` 真实存在的 GitHub 载体只有：

- `README.md`
- `亭子_v1.md`
- `因子_all.csv`
- `因子/`
- `状态`

旧链接指向的以下页面没有以同名干净页落地：

- `Alpha决策指南 ...md`
- `WQB知识附录 ...md`
- `条件化行为地图 ...md`
- `探针与假说（第23-24轮） ...md`
- `工坊 ...md`

因此本轮不能把旧 UUID 链接简单改成同名干净路径。正确处理是：

1. 保留旧页名作为索引线索；
2. 删除会误导读者的死链接；
3. 指向已经实证存在的当前量化载体：`领域/量化/README.md`、`亭子_v1.md`、`因子_all.csv`、`因子/`。
