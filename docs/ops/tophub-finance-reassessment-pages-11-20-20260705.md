# 累计 240 节点后的候选池

## A1 强候选

### 1. 有知有行｜全部

角色：长期投资、基金、保险、资产配置、数据与行为。

优势：

- 不以每日价格变化为中心；
- 与用户长期、分散、定投型方法一致；
- 能把市场波动放回组合、风险与生活；
- 与现有新闻源角色不同。

风险：

- 含自有产品和账户体系；
- 不能把其组合动作当成用户指令；
- 最终应订阅`全部`，不订`知行黑板报`。

### 2. 日经中文网｜每日最新

仍是日本、东亚、供应链与货币政策的首选候选。

### 3. 财新编辑入口

最终只在以下两者中选择一个：

- `财新网｜首页推荐`；
- `财新网｜最新文章`。

现有点击排行榜和评论排行榜均处于被替换位置。

# 当前架构判断

## 1. 有知有行比新增市场媒体更重要

前 240 个节点中，市场新闻已经极度饱和。真正缺少的是帮助用户保持长期尺度、理解组合与保险边界的低噪声来源。`有知有行｜全部`首次补上这一角色。

## 2. 财新应从排行榜改为编辑入口

目前最可能的最终动作不是增加财新，而是：

- 取消点击排行榜；
- 取消评论排行榜；
- 选择首页推荐或最新文章之一。

## 3. 亚洲视角可以形成两点结构

- 日经中文网：日本与东亚产业 / 货币；
- 联合早报：新加坡、东南亚与全球华语财经。

是否两者都留，要看剩余 84 个节点是否出现更强来源。

## 4. Web3 最终可能不是“只留一个”

经过 240 个节点后，角色差异已经清楚：

- 慢雾：安全；
- Foresight / 链捕手 / ChainFeeds：中文生态与结构；
- CoinDesk：英文原始报道。

最终可以是“安全 + 中文结构”两条线；英文源只有在 Folo 容量和阅读负担允许时再加入，不能机械地按媒体数量限制。

## 5. 国家金融与发展实验室不需要日更

它更适合：

- 写入沃壤研究源；
- 在宏观、数字资产、金融风险和监管问题出现时调用；
- 不承担每日阅读或未读清零。
