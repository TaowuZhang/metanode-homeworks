## TopHub 决策

### 1. 推书君三个榜不新增

#### 完本榜

它更像一份已经沉淀的中文网文经典目录，包含《诡秘之主》《放开那个女巫》《修真聊天群》《全职高手》《奥术神座》《秦吏》《绍宋》等作品。

用途是：

- 想找一部已经完结、口碑相对稳定的网文时按需查询；
- 回顾中文网文的类型史、经典作品与长期影响；
- 不需要承担当前趋势发现。

不新增的原因：

- 排名变化慢；
- 与榜中大量经典书单和网络讨论高度重复；
- 会继续扩大“以后可能读”的库存，而不是帮助真正开始一本书。

#### 畅销榜

榜中大量作品分值为 0，且混合当前起点热门作品、同人、影视衍生、官场模板、四合院与重生题材。

它既不能稳定代表销量，也不能稳定代表质量，更适合作为网文平台题材与标题模板的临时样本，不进入订阅系统。

#### 新书榜

几乎全部条目分值为 0，无法说明作品质量、读者认可或真实成长趋势。

明确排除，不作为常驻、候选或追踪来源。

### 2. 七猫十四个榜不新增

4. 男频与女频榜各自能够反映七猫用户结构，但不需要进入用户的日常阅读流；
5. 用户真正需要研究网络文学市场时，可以直接打开对应榜单，而不必持续订阅全部切片。

### 3. 百度｜小说榜不新增

百度小说榜聚合搜索热度，当前同时出现：

- 起点与七猫热门作品；
- 长期经典网文；
- 历史、玄幻、都市、女频和影视带动作品。

它能回答“目前百度用户正在搜什么小说”，但不能回答：

- 哪本值得读；
- 哪本真正新；
- 哪个作者值得长期关注；
- 哪种趋势来自真实阅读，哪种来自影视、广告或搜索联想。

它与起点、七猫、微信读书以及推书君的热度入口高度重复，只作为临时交叉核验工具。

### 4. `我不是盐神`不新增

- 数学、系统和社会悖论；
- 科技法律与平台史；
- 音乐演出；
- 现代性、读书和个人经验。

它更适合 Folo，而不是 TopHub，原因是：

1. 价值来自同一个作者如何跨领域建立联系，不来自标题排名；
2. 文章跨度与用户需要的“不同视角”相符，但并非无中心的杂项堆积；
3. 内容低频、标题密度高，不容易造成未读洪水；
4. 与现有技术新闻、长报道和理财来源的功能不同；
5. 其中既有理性分析，也有音乐、个人经验和较轻的写作，适合放在 Folo 的深读与漫游边界。
