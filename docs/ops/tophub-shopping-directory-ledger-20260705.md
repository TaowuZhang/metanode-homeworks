- `美国信用卡指南`、美卡论坛和 V2EX 信用卡仅在具体跨境支付或卡产品任务中按需检索。

## 购物目录的最终角色

购物不承担持续发现“可以买什么”，而承担明确需求发生后的六步任务：

1. 写清需求与使用场景；
2. 确定规格、预算和不可妥协条件；
3. 搜索候选商品与渠道；
4. 核验历史价、型号、认证、版本、保修、退换与售后；
5. 对健康、金融、母婴、药品和医疗器械提高证据门槛；
6. 购买完成后结束任务，不把促销流长期留在注意力中。
