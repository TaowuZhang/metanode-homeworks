## 一、为什么取消虎嗅网｜热文

当前热文样本混合：

- 普通人休闲与刷手机；
- 字节商业化；
- 欧洲空调；
- 韩国经济政策；
- Token 成本；
- 奈雪经营；
- 劫机事件；
- 王兴人物报道；
- 芯片与存储涨价；
- 创业者融资；
- 苹果泄密；
- 新能源政策；
- AI 收费；
- Meta 与存储市场。

它并非纯科技入口，而是科技、商业、消费、社会、人物和情绪议题的混合热榜。

主要问题：

1. 标题强烈依赖冲突、危机、反转和情绪张力；
2. 文章范围过宽，无法形成稳定的科技职责；
3. 与 36氪、极客公园、爱范儿、Readhub、IT之家大量重复；
4. 与公共温度中的商业和社会热点也发生交叉；
5. 热度排序不能证明文章的事实质量、方法透明度或长期价值；
6. 当前科技雷达已经拥有足够多的中文科技与商业入口。

因此，虎嗅热文继续常驻只会增加相似叙事，不会补出新能力。

## 二、与 36氪｜深氪的关系

36氪小标签已经形成替换建议：

- `36氪｜24小时热榜` → `36氪｜深氪`

在这一前提下继续保留虎嗅热文，会形成两个高度相邻的中文商业产业叙事入口。

二者都关注：

- AI 与大公司；
- 资本市场；
- 消费品牌；
- 汽车；
- 创业与融资；
- 组织与人物；
- 技术变化对行业的影响。

相比之下，`深氪` 至少具有更明确的低频长报道与公司产业过程角色；虎嗅热文主要是全站热度切片，边界更不稳定。

因此本轮建议：

- 36氪保留一个低频产业长报道入口；
- 虎嗅不再保留常驻节点；
- 具体虎嗅文章在搜索、转载或其他入口遇到时按需阅读。

这不是认为虎嗅所有文章都没有价值，而是不再为整个平台维持常驻热榜入口。

## 五、虎嗅网｜早报

**不新增。**

早报将国际政治、战争、平台企业、消费品牌、房地产、资本市场、AI、汽车和政策压缩在同一条多事件标题中。

问题：

- 与公共温度及其他早报、快讯高度重复；
- 对科技雷达没有稳定的独特职责。

## 七、按需使用方式

虎嗅保留为按需页面，而不是常驻节点。

适合的场景：

- 某家公司或行业事件需要寻找中文商业叙事；
- 想观察一件事如何被产业媒体解释；
- 需要对照 36氪、晚点、财新等来源的叙事差异；
- 已经看到具体虎嗅文章标题，需要进一步判断全文。

不适合：

- 每天扫全站热文；
- 将虎嗅当成事实核验或一手来源；
- 将早晚报当成必须清空的信息流；
- 在 Folo 中持续接收全站更新。
