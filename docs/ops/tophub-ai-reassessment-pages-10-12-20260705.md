## 第 10 页｜12 个节点

### 1. cs.CL updates on arXiv.org

**研究查询与追踪入口，不订阅整个分类。**

自然语言处理分类每天可出现大量论文，当前样本已覆盖 Agent 评测、RAG、对齐、安全、医疗、多语言、语音和推理。价值很高，但未读负担不可控，标题也不能替代论文质量判断。

正确路由：围绕具体关键词、作者、论文或问题建立临时检索与追踪，不订阅整个 cs.CL 信息流。

### 2. cs.CV updates on arXiv.org

**研究查询入口，不订阅整个分类。**

适合查视频、视觉语言模型、世界模型、3D、生成影像、自动驾驶和医学影像；不适合每天接收完整分类。

### 3. cs.LG updates on arXiv.org

**研究查询入口，不订阅整个分类。**

机器学习总分类范围更宽，包含量子、联邦学习、强化学习、压缩、世界模型和大量理论工作。作为常驻流会制造极高噪声。

### 4. Tech.eu｜Deeptech

**不订阅。**

主要是欧洲深科技融资、政策和创业公司，AI 只占部分内容；与现有科技与财经媒体重复。

### 5. Superlinear - Medium

**排除。**

内容混合表示学习、生成图像、企业 AI 和“买还是建”等宽泛议题，更新与作者责任关系不清，Medium 聚合也增加质量波动。

### 6. philschmid.de

**A1 强候选。**

当前内容高度贴近用户实践：

- Agent Skill、AGENTS.md、Harness、Context Engineering；
- MCP 服务器与 CLI；
- 单 Agent / 多 Agent、内外循环与可靠性；
- Codex CLI、Gemini API、Computer Use、Deep Research；
- Hugging Face、开放模型、微调、评测与部署。

优势：

- 教程直接、工程步骤明确；
- 同时连接 Google、Hugging Face、AWS 与开放模型生态；
- 比企业新闻更接近“怎么做”；
- 比零散教程站更有作者连续性。

限制：

- Google / Gemini 与云平台内容占比较高；
- 部分文章是具体产品教程，可能随 API 快速过期；
- 仍需和 Simon Willison、O’Reilly Radar 比较重复度。

初步路由：Folo 技术阅读或低频触发。

### 7. Mozilla Foundation Blog

**B+ 慢读条件候选。**

关注开放技术、语言包容、AI 偏差、身体数据、非洲与全球南方议题，能补充主流产品和工程来源较少覆盖的权力、语言与公共利益问题。

但它不是持续 AI 工程源，更新也包含组织活动与资助项目。更适合慢读与思想，而非科技雷达。

### 8. Latent.Space

**A2 / B+ 强条件候选。**

价值：

- AI engineering、Agent loop、Skill engineering、software factory、本地 AI 与企业部署；
- 能连接工程师、创业者、研究者与实际产品；
- 议题与当前 Agent 工作流高度相关。

限制：

- AINews 和 Daily Dispatch 更新频率偏高；
- 新闻、访谈和活动内容混排；
- 容易与 O’Reilly Radar、Simon Willison 和 InfoWorld 形成重复。

若最终选择，应优先寻找周刊或精选入口，而不是订阅全部日更。

### 9. KDnuggets

**明确排除。**

大量“10 个框架”“5 个工作流”“最佳订阅计划”式清单和教程标题，搜索导向强，质量与深度波动大。

### 10. Interconnects

**A1 强候选。**

当前内容聚焦：

- 开放模型与闭源模型生态；
- 后训练、蒸馏与开放工件；
- 中国 AI 实验室；
- 模型治理、权重开放和产业结构；
- 模型性能差距与长期下注。

它补充的是“模型生态与训练路线怎样变化”，与 O’Reilly Radar 的 Agent 工程、Hugging Face Blog 的官方技术形成角色差异。

限制：作者对开放模型与治理有鲜明判断，需要作为一个持续视角，而非中立裁判。

初步路由：Folo 深度阅读。

### 11. Wolfram Blog

**慢读按需，不与 Stephen Wolfram Writings 重复订阅。**

内容兼具 Wolfram 产品、数学、计算与科学文章。若最终建立关系，应在 Wolfram Blog 与 Stephen Wolfram Writings 中选一个，且放慢读系统，不放 AI 雷达。

### 12. Weights & Biases｜Fully Connected

**旧播客档案，不订阅。**

历史访谈质量很高，但榜单主要是长期存档，不能承担当前更新。需要具体人物时按集回看。

## 第 11 页｜12 个节点

### 1. Blog on LlamaIndex

**产品与文档处理任务型入口。**

Retrieval Harness、LlamaParse、OCR、KYC、法律发现和文档自动化都很实用，但强绑定 LlamaIndex 产品。实际做文档解析、RAG 或合规流程时访问。

### 2. Unwind AI

**陈旧且已并入 Last Week in AI，排除。**

页面明确显示已迁移，并把用户导向 Last Week in AI；现有 Folo 已有后者。

### 3. The Algorithmic Bridge

**批判视角按需，不常驻。**

能讨论 AI 劳动、能力退化、行业结构和公众反弹，但标题冲突性和结论性很强，近期又高度集中于 Anthropic。适合需要反方材料时打开，不作为默认理解框架。

### 4. TechSpot

**被现有科技雷达覆盖，不从 AI 目录新增。**

综合硬件、操作系统、游戏和科技新闻，AI 只占部分内容。

### 5. Tech Monitor

**不订阅。**

企业云、主权、裁员、融资和公司发布占主导，与商业科技媒体重复。

### 6. Stories by ODSC - Open Data Science on Medium

**按需，不订阅。**

有 Agent 测试、生产治理、医疗 GraphRAG 和开源项目等可用文章，但 Medium 投稿与会议内容混合，稳定筛选能力不足。

### 7. Simon Willison's Weblog

**A1 强候选；属于既有关系升级，而非新发现。**

沃壤已经存在该站的长期链接记录。当前样本显示它持续覆盖：

- 实际 Coding Agent 开发与成本；
- Datasette、sqlite-utils、LLM 工具和小型开源项目；
- Prompt / SQL 评测；
- Agent 录屏、工具测试和真实安全事件；
- 开放模型、浏览器工具与模型发布。

优势：

- 亲自实验并给出代码、数字和失败记录；
- 更新快，但通常能追到原始来源；
- 与用户的 Codex、GitHub、工具链和安全边界高度相关；
- 不只评论 AI，也持续产出可使用的软件。

限制：

- 更新量较高；
- 短引用、工具发布和长文混排；
- 特定时期会集中追踪某一厂商或模型。

最终问题不是“值不值得认识”，而是沃壤链接图是否已经足够，还是要升级成 Folo 持续源。当前综合排名进入第一梯队。

### 8. Qdrant - Vector Database

**检索任务型官方源。**

向量搜索、稀疏检索、混合检索、多向量、边缘搜索和 Agent Memory 内容专业，但强绑定 Qdrant。做 RAG、搜索或向量数据库选型时使用。

### 9. Not So Standard Deviations

**不订阅。**

数据科学闲谈与旧节目占比高，更新稀疏，AI 不是稳定主线。

### 10. NLP Highlights

**陈旧档案，排除。**

仅显示极少量旧节目，不能承担当前 NLP / LLM 信息入口。

### 11. MLOps.community

**B+ 强条件候选。**

议题非常贴近生产 Agent：

- Sandbox、Harness、MCP、Evals、Observability；
- Agent 团队、可靠性、上下文工程；
- 生产部署、GPU、检索、成本与治理。

问题是内容量巨大，视频、圆桌、采访和厂商活动混排。更适合作为任务型视频库或精选订阅，不适合完整吞入未读流。

### 12. Gradient Dissent｜Conversations on AI

**人物访谈库，按需。**

嘉宾质量不错，涵盖基础设施、搜索、机器人、AI4Science 和开源生态；但节目数量大、供应商和 CEO 访谈多，按人或主题选择即可。

## 第 12 页｜12 个节点

### 1. Nicholas Carlini

**A1 / A2 交界的高信号作者候选。**

内容覆盖：

- 对抗样本与安全评测；
- 基准设计、研究方法与论文发布；
- 对 AI 预测的复盘；
- 实际使用 AI 写网站和小型系统；
- 隐私、版权与生成式 AI；
- 低层编程和硬件实验。

优势：低频、原创、技术能力强，能够暴露评测和安全论证中的薄弱环节。沃壤已有其他材料引用其研究，但未发现该博客的持续订阅关系。

限制：主题并不只限于 AI，且作者已进入 Anthropic；仍应按文章证据判断，不因机构身份扩大或削弱其观点。

初步路由：Folo 深度阅读或沃壤高价值作者链接。

### 2. MarkTechPost

**明确排除。**

高频论文和产品摘要，标题持续使用“发布、达到、突破、开源”等结构，缺少对论文限制、复现和来源质量的充分筛选。

### 3. LangChain Blog

**重复节点。**

沿用第 8 页判断：B+ 条件候选，只有实际采用 LangChain / LangGraph / LangSmith 时才升级。

### 4. Home on Nan Xiao｜肖楠

**个人技术博客，按需。**

R、Rust、统计软件、字体、可视化和 AI 工具实验有质量，但主题过宽，不是通用 AI 入口。遇到 R 包工程、Rust CLI、统计图形或相关 AI 工具时回看。

### 5. Gradient Flow

**B+ 条件候选。**

当前样本集中于：

- Agent map 与 context；
- 数据合规；
- 模型无法替代的数据责任；
- AI 成本、Tokenomics、基础设施和能源。

它能补充模型新闻忽略的数据与经济约束，但与 O’Reilly Radar、InfoWorld 和 Ben Lorica 相关内容可能重叠。保留到最终比较。

### 6. Towards AI - Medium

**排除。**

教程和热点标题密集，作者与编辑责任关系不清，且容易形成大量同质 Agent 教程。

### 7. DataTalks.Club

**开放学习社区，任务型保留。**

生产 AI、MLOps、数据工程、职业路径和开源课程内容丰富。适合需要课程、访谈或社区学习时使用；完整订阅会带来过多会议与职业内容。

### 8. Adventures in Machine Learning

**不订阅。**

节目覆盖商业、职业、管理和机器学习，范围太宽且时间成本高。具体嘉宾或主题按集使用。

### 9. Computerworld

**不从 AI 目录新增。**

企业 IT、安全、微软、Apple 和 AI 治理混合，与现有科技媒体和 The Register 重复。

### 10. SiliconANGLE｜AI

**不订阅。**

融资、企业发布、合作和供应商新闻占比高，接近企业科技快讯。

### 11. Futurism

**与第 9 页 AI News 节点重复，明确排除。**

完整站点同样依赖极端、灾难和嘲讽性标题，并进一步混入大量非 AI 内容。

### 12. Together.ai

**B+ 技术供应商候选 / 高价值按需。**

优势：

- 开放模型推理、训练、RL、Kernel、长上下文和代码 Agent；
- 有实际基准、系统优化和研究文章；
- 与开放模型和低成本推理有关。

限制：

- 产品发布、融资和平台宣传数量很大；
- 自家推理服务与合作伙伴内容占主导；
- 不能把供应商基准当作独立结论。

实际评估开放模型推理、Together API、训练基础设施或 Kernel 时优先访问；是否常驻留待最终压缩。
