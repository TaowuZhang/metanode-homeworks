### 2. 是否加入 Folo / Follow？

**本批继续形成 Folo 复查候选池，不直接加入真实 Folo。**

优先候选：

1. `Simon Willison's Weblog`  
   价值：AI 工具、LLM、SQLite、数据工具、Web 工程与可复现写作，作者质量高。  
   风险：更新频率高，容易成为主未读源；若进入 Folo，应是 AI/工程作者池强候选。

2. `Latent.Space`  
   价值：AI 工程、Agent、模型生态与行业实践，和用户当前 Agent 工作流高度相关。  
   风险：播客/长文密度高，需与 Interconnects、OReilly Radar、Ahead of AI 等统一比较。

3. `Interconnects`  
   价值：开放模型、AI 生态、训练与政策/产业判断，适合 AI 研究观察。  
   风险：观点型强，不能替代一手论文或官方文档。

4. `Blog on LlamaIndex`  
   价值：RAG、文档解析、Agent 数据管线和企业检索。  
   风险：企业生态源，需与 LangChain、Qdrant、Jina AI 统一去重。

5. `Qdrant - Vector Database`  
   价值：向量数据库、检索质量、弱检索预测和 RAG 基础设施。  
   风险：官方产品源，适合 RAG/搜索专题，不适合泛读。

6. `The GitHub Blog`  
   价值：GitHub 平台、安全、secret scanning、maintainer 设置和开发者生态。  
   风险：内容面较宽，需确认是否比 GitHub Security Lab 更适合当前系统。

7. `Daring Fireball`  
   价值：Apple、原生应用、软件文化和个人作者判断。

8. `Craig Mod`

   风险：非技术源，更新节奏和阅读意愿需确认。

9. `Mozilla Foundation Blog`  
   价值：开放互联网、AI 包容性、Common Voice 和公共技术议题。  
   风险：基金会/公共倡议口径强，应和 Mozilla Security / Mozilla 技术源区分。

10. `Wolfram Blog`  
    价值：Wolfram Language、计算、数学、AI 与知识系统。  
    风险：专题性强，适合知识系统/数学/AI 交叉池。

11. `Weights & Biases: Fully Connected`  
    价值：ML 工程、实验追踪、AI/科学和企业实践。
