# WQB Alpha Mountain Protocol v1

1. Seed：经济假设。字段为什么可能有效。
2. Prototype：简单表达。operator_count 尽量低。
3. Backtest：初筛。只回答是否有信号。
4. Robustness：扰动测试。horizon / decay / neutralization / truncation。
5. Originality：self/prod/power-pool correlation 与 data diversity。
6. Portfolio Fit：最终生态位。只有 gates 全 pass 才 final_click_candidate。

每个 Alpha 在六亭中只前进一亭，不允许从 Prototype 直接叫 final-click。
