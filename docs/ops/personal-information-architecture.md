# 外部信息架构草案：脉搏 / 工作台 / 陈列柜

这份文档从原 `成为/项目/建·个人页面.md` 中抽出，重新排列为面向 Web 第一版与 Notion 公共入口的外部信息结构大纲。
这里的架构不包含隐私数据与未跑通的后端代码，而是直接面向陌生访客的“好奇缺口”与“信任锚点”。

## 1. Pulse（脉搏）

**定位**：当前生命体征，回答“我现在在用多大力气干什么”。
**形式**：用高频数据、进度条与当前 OKR 代替静态简介。

*   **KPI（体征读数）**
    *   例如：7 年晨跑不断 / 近 30 天的代码提交密度 / Hack The Box 房间打通数。
    *   用最简单、不夸大的数字，证明持续性。
*   **OKR（当前瞄准的切面）**
    *   例如：网络安全渗透测试 / 编程系统构建 / 量化信号验证。
    *   明确当前主要的推进方向。
*   **超越叙事**
    *   一句关于“为什么选这条路”的底层逻辑。
    *   例如：“拆解系统、构建系统、用数据验证系统——同一种思维方式的三个出口。”

## 2. Workbench（工作台）

**定位**：正在推进的工程 / 学习 / 内容项目。
**形式**：进行中的卡片，强调“进行时”而不是完美成品。

*   **💻 拆解与构建**
    *   比如 10.5 万行核心代码的经历，从算法题重推的数据结构。
    *   比如网安渗透测试全链路学习记录。
*   **📊 验证（量化金融）**
    *   已提交的 WorldQuant Brain 因子设计与数据反馈。
*   **📦 孵化中（内容线）**
    *   例如“彼岸此地杂货铺”：对外表达的尝试与草稿箱。

## 3. Cabinet（陈列柜）

**定位**：坐标故事与认知转折。
**形式**：Teaser → Depth。直接裸陈最重要的认知转点。

*   **挑选 3-4 个决定性坐标**：
    *   *一片冰心在玉壶*（坚守真诚）：在大人世界里不找借口的坚持。
    *   *不识庐山真面目*（认知探索）：在应试环境中讨论正义与责任。
    *   *问心无愧天地宽*（独立路径）：在代写泛滥的环境中独自做饭与求学。
    *   *半江瑟瑟半江红*（融合边界）：从文字开始认识坂本龙一，理解自在。
*   **交互逻辑**：先铺几段核心引文/引语，点击后才深入全文明细。
