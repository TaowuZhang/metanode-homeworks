## 审核原则

本目录不按“编程网站越多越好”处理，而按角色判断：

1. 是否提供原始、稳定、可复查的工程信息；
2. 是否补足现有 `HelloGitHub｜月刊`、`The Register｜Latest`、`先知社区｜精华推荐`和官方直接源；
3. 是否只是 AI Coding、Agent、MCP、Loop、Harness 或 Skill 热点的重复包装；
4. 是否绑定当前真实学习、仓库或项目；
5. 是否会制造跨语言、跨技术栈、永远清不完的未读流；
6. 是否更适合作为任务资料库、官方文档、项目索引或搜索入口；
7. 是否错位混入产品、营销、出海、职场、消费、融资或交易内容；
8. GitHub Trending 的标签是否真的反映生态，而不是主语言或聚合映射异常；
9. Hugging Face 的 Models、Spaces、Datasets 排行是否只是检索工具；
10. 候选、实际订阅和精确追踪器严格分开。
