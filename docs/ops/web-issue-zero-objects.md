# Web 第零期物件语法 v0.1

时间：2026-05-09
关系：承接 web-issue-zero-brief.md / web-issue-zero-retrospective.md

## 物件写法
每个物件三层：远看=气味；中看=解释；近看=来源、痕迹、证明、反默认判断、关联。

## 01 三意象
远看：三件旧物，被重新摆成进入网站的门。
中看：场刊负责入场，工作室负责重组，证据场负责显影来路。
近看：
- 来源：对个人网站不想落入简历/作品集/Notion 页的反抗。
- 痕迹：三意象贯穿方法、brief、回顾。
- 证明：网站可先有物理组织法，再有视觉。
- 反默认：意象不是风格模板。

## 02 意志保护 / 反猜意图护栏
远看：不要猜我，先把靠近方式递给我。
中看：它把 AI-UX 的意图驱动降级为显式场位与意志保护。
近看：
- 来源：谷挑战“是谁的意图”。
- 痕迹：显式场位、观看姿势、靠近方式。
- 证明：伦理边界先于交互效果；第一使用者不是系统预测对象。
- 反默认：用户行为不是系统猜意图的许可。

## 03 物理语法方法文档
远看：一块给网站打地基的石头。
中看：web-physical-grammar-synthesis.md 把三意象与 UIUX 资料压成施工原则。
近看：
- 来源：Shape of AI、AI-UX、Refactoring UI、Laws of UX、Sajid Code UI。
- 痕迹：commit 与 push。
- 证明：研究不是停在总结，而能转为约束。
- 反默认：资料总结不等于设计。

## 04 第零期 brief
远看：开张前的节目单。
中看：它确认这轮不是第一期，而是试运行本身。
近看：
- 来源：谷提出“这件事本身值得记录”。
- 痕迹：web-issue-zero-brief.md。
- 证明：生成过程可以成为内容。
- 反默认：网站不必等完成才出现。

## 05 第零期回顾
远看：把脚印倒着照亮。
中看：它记录路径、否定、张力和收束。
近看：
- 来源：谷要求记录是与不是，以及过程中的张力。
- 痕迹：web-issue-zero-retrospective.md。
- 证明：否定路径也是证据。
- 反默认：只记录结论会丢失判断力。

## 06 UIUX 导入过程
远看：外部资料被搬进土壤。
中看：导入不是囤资料，而是让资料各自承担角色。
近看：
- 来源：Shape of AI / AI-UX / Refactoring UI / Laws of UX / Sajid Code UI。
- 痕迹：Notion 导入页与方法文档。
- 证明：参考资料可被转译为护栏、刹车、手感。
- 反默认：更多资料不自动等于更好设计。

## 07 终端桥
远看：让讨论落到地上的桥。
中看：它把对话、Notion 终端、本地文件、git commit 连成回路。
近看：
- 来源：长期需要让 AI 协作可执行。
- 痕迹：终端页回填、commit、push。
- 证明：AI 协作靠协议和边界，不靠人格想象。
- 反默认：聊天不是沉积。

## 08 Apple / NNGroup 缺席位
远看：两块还没运到现场的大石头。
中看：它们暂不阻塞，只作为后续补审槽。
近看：
- 来源：下载体量过大，Apple 约 1G+，NNGroup 约 6G+。
- 痕迹：brief 与方法文档中的补审槽。
- 证明：等待资料不能替代施工。
- 反默认：资料不到齐也能推进可逆部分。

- 工作室：01/03/06/07 组织为材料关系。
- 证据场：02/03/05/07 强调决策、痕迹和反默认。
- 幕后施工：04/05/08 显示未完成与后续补审。
