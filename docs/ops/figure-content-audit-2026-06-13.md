## 1. 统一线义词汇（沉积流图谱通用）

以下词汇适用于「全空间运行流图 / 全景合体图 / 雕工札记 / 空间飞轮图」四个图族：

- 实线 `-->` ＝ 主流向 / 主沉积链。
- 粗实线 `==>` ＝ 跨层 / 跨空间主沉积链（沉积 · 硬事实回供 · 成熟出土）。
- 虚线 `-.->` ＝ 支撑 / 反向 / 漏出 / 仍薄未接线。
- 实线框 ＝ 已建（在转）。
- 虚线框（`stroke-dasharray:5 3`）＝ 待建 / 半轮 / 很薄。
- 💤 灰虚线框 ＝ 休眠（设计完整、暂未启用、即醒、不摘牌）。
- ⚠ ＝ 漏点。
- 色温双通道（按出入场底谱）。

**例外（#227 拓扑四图）**：结构图 / 状态机 / 圈路图 / 博物位置图是拓扑·状态·流程图，不是沉积流图。它们的线＝结构连接 / 状态转移 / 流程推进，不套用 `==>` 主沉积链词汇；该四图已就地加「对照式线义约定」声明区别。
