## 判断

当前这轮不是第一期，而是第零期试运行。

第零期的价值不在于展示一个已经完成的个人网站，而在于记录：一个个人现场如何从三意象、参考资料、意志保护 / 反猜意图护栏、本地终端桥和真实协作中生成。

它本身就是材料：
- 我们不是先做门面，而是在做进入条件。
- 我们不是先做视觉稿，而是在做物件语法。
- 我们不是用 AI 猜访客意图，而是在建立显式场位与靠近方式。
- 我们不是把 AI 当主语，而是在 AI 时代保持物理语法、来路、现场和克制。

## 开场一句

这不是正式发布的一期，而是网站生成前的试运行：把场刊、工作室、证据场三种意象放到桌上，先看它们如何组织材料、显露来路、抵抗猜意图，并保护第一使用者的靠近方式。

## 本期节目单

1. 三意象立住
   - 场刊负责入场。
   - 工作室负责重组。
   - 证据场负责显影来路。

2. 意志保护 / 反猜意图护栏
   - 不用「意图驱动」作核心词。
   - 改用意志保护、显式场位、观看姿势、靠近方式。
   - 不根据隐性行为改写叙事。
   - 不把用户行为当成系统猜意图的许可。

3. UIUX 资料进入土壤
   - Shape of AI 提供 Wayfinders / Governors / Trust indicators。
   - AI-UX 提供时代经验，但不 AI 化。
   - Refactoring UI 和 Sajid Code UI 提供落地手感。
   - Laws of UX 提供认知负荷与可用性刹车。

4. 本地沉积完成
   - docs/ops/web-physical-grammar-synthesis.md 已写入并 push。
   - 第零期 brief 作为下一步内容剧本入口。

5. Apple / NNGroup 暂作补审槽
   - 等大文件导入后，再补空间连续性、信息气味、渐进披露、可发现性。

## 第零期不做什么

- 不做正式首页。
- 不做视觉奇观。
- 不做 AI 导览员。
- 不根据访客行为猜意图。
- 不等 Apple / NNGroup 才继续。
- 不把资料总结当成设计本身。
