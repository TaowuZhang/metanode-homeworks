## TopHub 决策

### 1. 保留 `微信读书｜新书榜`

它继续承担中文数字出版的新书与新刊发现：

- 同时出现图书、杂志和较新的长篇作品；
- 能看见微信读书书库内部正在新增和被发现的内容；
- 与豆瓣新书速递相比，一个偏数字阅读平台的新入库和即时消费，一个偏图书出版与读书社区，两者并非完全重复。

它不是质量裁判，但作为入口仍然有效。

### 2. 新增 `书格｜每日好书`

这是本页最明确的 TopHub 增量。

当前样本包括：

- 《铁华馆丛书》；
- 《御制避暑山庄诗图册》；
- 《道经四种》；
- 《龙池竞渡图卷》；
- 《墨谱》；
- 北宋版《通典》；
- 《钦定曲谱》；
- 八大山人写生册。

它与现有来源的区别是：

1. 不是畅销榜、热搜榜或推荐值榜；
2. 不是现代出版营销入口；
3. 直接提供古籍、画册、书法、谱录和历史图像档案的发现；
4. 标题目录本身已经足以决定是否打开，因此适合 TopHub，而不必占用 Folo 的长期关系位；
5. 它补充的是原始文化材料与数字典藏，而不是再增加一张“大家最近在读什么”的榜单。

#### 拟定位置

- 分组：慢读与思想；
- 组内第 10；
- 全部第 50；
- 放在 `豆瓣电影｜最受欢迎的影评`之后、`器物于我`之前。

该位置在当前基线和现有豆瓣待执行方案完成后都保持为组内第 10、全部第 50。

### 3. 不新增微信读书其余榜单

不新增：

- 总榜；
- 飙升榜；
- 热搜榜；
- 神作榜；
- 神作潜力榜；
- 小说榜；
- 男生小说榜；
- 女生小说榜。

理由：

- 总榜长期被经典畅销书占据，变化慢；
- 飙升和热搜容易受影视、热点、营销、自媒体书和短期话题驱动；
- “神作”“神作潜力”的高推荐值并不等于稳定策展，样本里同时出现经典文学、轻科技、命理、心理成长、理财与平台轻内容；
- 小说、男生小说和女生小说会把阅读入口再次拉回网络小说消费池；
- 当前 `新书榜`已经是微信读书中最有明确用途的一张榜。

### 4. 不新增当当畅销图书榜

当前样本质量不差，出现民族志、文学经典、许倬云、兰小欢等书，但它仍是销售结果：

- 容易受库存、活动、折扣、出版营销和平台用户结构影响；
- 与微信读书新书、豆瓣新书速递、豆瓣热门书籍和书评入口重复；
- 用户不需要再增加一张购书平台销量榜。

保留为准备买纸书或观察某个出版周期时的按需入口。

### 5. 网络文学平台榜不新增

本页大量节点来自起点、起点女生、纵横、七猫和推书君，同一内容池被切成：

- 畅销、阅读指数、月票、点击、推荐、收藏、书友、捧场；
- 新书、签约作者新书、新人作者新书、公众作者新书；
- 限时免费、更新字数、总字数、单订；
- 男频、女频、完结、原创风云、原创飞跃。

这些榜单适合回答具体市场问题，例如：

- 当前男频或女频题材在流行什么；
- 哪些新作者或签约作者正在冒头；
- 某平台的付费、月票、收藏和点击是否一致；
- 某本连载作品在不同平台指标中的位置。

但不适合作为日常订阅流：

1. 同一批作品跨榜反复出现；
2. 平台指标受推荐机制、付费结构和站内运营影响；
3. 标题同质化严重；
4. 会制造巨大的候选书单，却不提高真正开始阅读的概率；
5. 用户已经有微信读书新书榜，以及起点、纵横、七猫各自审核后留下的按需入口。

#### 仍可按需使用

- 起点中文网｜阅读指数榜；
- 起点女生网｜阅读指数榜；
- 起点中文网｜签约作者新书榜；
- 纵横中文网｜月票榜、完结榜、24小时畅销榜；
- 七猫中文网｜男女频新书榜与完结榜；
- 推书君｜完本榜：只作旧网文经典目录，不作当前趋势榜。

#### 明确排除

- 推书君｜新书榜：样本几乎全部为 0 分，缺乏有效筛选；
- 各类总字数、VIP更新字数、24小时更新榜：衡量更新量而非作品价值；
- 大量收藏、书友、捧场和单订榜：站内运营指标，不值得进入跨来源阅读系统。

### 6. `书伴`不新增

它是 Kindle 设备、固件、越狱和硬件资讯站。当前样本主要围绕：

## Folo 决策

### 第一优先候选：`基本読書`

`基本読書`不是普通书榜，而是一个持续进行选书和长篇评论的日文读书站。

当前样本覆盖：

- 日本与英美科幻；
- 科学非虚构、生命科学、免疫、代谢和道路生态学；
- 经济、债务、保险与资本主义；
- 性别、公共社会、民主与威权；
- 拉丁美洲恐怖、心理小说和世界文学；
- 年度阅读回顾和专题推荐。

它值得进入 Folo，而不是 TopHub，原因是：

1. 真正有价值的是持续的编辑判断与评论文字，不只是标题排名；
2. 选题横跨科学、社会、政治、文学和科幻，与用户需要多视角的阅读方式高度一致；
3. 日文来源补上了当前 Folo 中缺少的日本本地阅读与出版视角；
4. 它适合慢慢建立对编辑口味的认识，而不是每天横向比较名次；
5. 与现有 `有知有行`、`Steph Ango`、长报道和科技来源不重复。
