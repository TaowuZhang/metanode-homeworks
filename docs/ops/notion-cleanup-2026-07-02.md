## 删除门

删除动作必须满足：

1. 页面属于上述旧系统；
2. 有用残差已经进入表中所列 GitHub 路径；
3. 公开页面及其父链被明确保留；
4. 删除列表由 Notion 在实际 replace / trash 操作前展开核对；
5. 若 Notion 报告额外子页，停止并重新判断，不把未知内容一并吞掉。
