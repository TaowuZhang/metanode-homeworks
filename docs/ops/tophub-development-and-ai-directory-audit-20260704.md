# TopHub「开发」与「AI」目录实测（2026-07-04）

## 范围

- 开发目录：约 290 个节点、25 页；
- AI 目录：约 215 个节点、18 页。

两页都不是单一主题的信息源，而是把媒体、社区、教程、项目榜、产品资讯、转载、营销内容和旧节点混在一起的目录层。

## 开发目录

### 1. GitHub Trending

`GitHub Trending Today` 与 `Trending Weekly` 能显示短期增长中的项目，但 stars 和上榜速度代表注意力，不代表：

- 项目成熟度；
- 代码质量；
- 安全性；
- 与沃壤或当前任务的适配度；
- 项目未来是否继续维护。

适合按需发现项目，不适合常驻订阅。真正采用前仍要看仓库活动、issue、release、许可证、维护者和代码。

### 2. CSDN 今日头条热点

当前页面在 2026 年仍大量展示 2025 年会议、Manus 初期、GPT-4.5、iPhone 16e 等旧内容，并出现重复条目。

结论：节点存在明显时间漂移，不作为实时开发入口，不订阅。

### 3. 掘金

`全站本周最热`、`人工智能本周最热` 和 `工具资源本周最热` 中确实能发现：

- Agent / Harness / RAG 工作流；
- 开源项目与工具；
- 具体故障排查；
- 工程实践文章。

但标题普遍受点击激励影响，混有夸张经历、教程包装、软性推广与重复热点。

用途：遇到具体技术问题时检索，或临时观察中文开发者社区正在讨论什么；不进入首页常驻层。

### 4. 人人都是产品经理

能看到 AI 产品、Agent、产品工作流、B 端系统和实际案例，也混合：

- 课程推广；
- “副业”“多赚一份收入”等转化内容；
- 高度模板化的方法论；
- 热点追逐和大量重复 AI 议题。

用途：具体产品问题出现后按题检索，不订阅日榜或最新榜。

### 5. 开源中国

热门资讯可提供软件版本发布与国内开源生态动态，但同时混有标题新闻、模型宣传和缺少原始来源的二次报道。

用途：作为版本发现入口尚可；真正需要时回到项目 release、官方文档或仓库。

当前不新增。

### 6. HelloGitHub

`HelloGitHub｜月刊` 是开发页中最清晰的低频候选：

- 更新频率低；
- 以开源项目为单位；
- 比日榜更适合漫游发现；
- 不要求每日处理。

#### 独立页面验证

已打开第 123 期：

`https://hellogithub.com/periodical/volume/123`

页面确认：

- 发布于 2026-06-29；
- 官方说明为每月 28 日更新一期；
- 按 C、C#、C++、Go、JavaScript、Kotlin、Python、Rust、Skills、Swift、人工智能及其他分类整理；
- 每个项目都提供简介、Star、Fork、项目链接和详情；
- 一期约 38 个项目，数量可控；
- 不是简单转录 GitHub Trending，而是编辑化筛选“有趣、入门级、实战和企业级”的开源项目。

第 123 期中与当前工作有较强关联的项目包括：

- `tolaria`：Git + Markdown 本地知识库，并带 MCP，接近沃壤与 Codex 的长期记忆场景；
- `llmfit`：根据本地硬件推荐可运行模型，和本地 Mac 推理选择相关；
- `stop-slop`：减少 AI 写作套路；
- `ponytail`：约束 AI 编程助手少写代码、减少过度工程；
- `SpeedyNote`：跨平台手写与旧设备再利用；
- `tiny-world-builder`：浏览器内体素世界创作；
- `micro-radar`、`optocamzero`：小型硬件与视觉项目。

这些项目的出现证明它与用户的技术漫游、工具判断和创作兴趣有真实交集；但月刊的作用是发现候选，不是要求逐个安装或纳入沃壤。

#### RSS 状态

当前独立页面没有可见的 RSS、Feed 或 Subscribe 入口；公开页面中也未直接发现 feed 链接。

因此来源判断为：

- **内容通过**；
- **更新节奏通过**；
- **订阅机制尚未验证**。

当前最合适的位置不是 TopHub 首页常驻，也不是立即加入 Folo，而是保留 `HelloGitHub｜月刊` 这一 TopHub 低频节点作为月度漫游入口。只有找到稳定官方 RSS，或 Folo 能通过页面自动发现可用订阅时，再考虑进入 Folo「漫游」或「观察期」。

### 7. 湾区日报

页面名为“最新期刊”，但样本包含大量旧文章与长期归档内容，不能承担实时更新节点。

它更像可检索的技术文化档案，不适合作为 TopHub 的当前榜单使用。

### 开发目录结论

- 不订阅 GitHub Trending；
- 不订阅 CSDN 今日头条热点；
- 掘金、产品经理、开源中国按问题使用；
- HelloGitHub 已通过内容与节奏验证，但订阅机制未验证；
- 当前科技雷达与 GitHub/Codex 工作流保持不变。

## AI 目录

### 1. 整体结构

AI 页把以下内容混在一起：

- 中文 AI 媒体与日报；
- 开发者社区热榜；
- 产品导航与工具推广；
- 国际科技媒体；
- 官方研究博客；
- 课程、代充值、教程和 SEO 内容。

它的主要功能是“看 AI 圈正在炒什么”，不是建立可靠的 AI 知识源。

### 2. 中文 AI 媒体的高度重叠

量子位、AIbase、36氪 AI 频道、AI 产品榜等大量重复同一批事件：模型发布、融资、Agent 产品、算力、机器人与公司新闻。

这些节点可用于发现事件，但标题叙事、转载和行业宣传较强。当前科技雷达已经包含 36氪、Readhub、极客公园、爱范儿、IT 之家等，不再增加同类节点。

### 3. 掘金 AI 热榜

能发现 Agent、RAG、Harness 与 Coding Agent 实践，但与开发页重复，且同样受热榜标题激励影响。

用途：问题驱动检索，不订阅。

### 4. MIT Technology Review

`Top Stories` 与 `All Stories` 在页面上内容重复，说明 TopHub 提供了多个近似节点。

MIT Technology Review 本身可作为跨学科科技媒体候选，但若以后需要，应直接检查官方 RSS，而不是同时订阅两个 TopHub 镜像节点。

当前不新增。

### 5. Google AI Blog

页面显示的条目大量停留在 2024 年研究内容，说明该节点可能是旧版博客、抓取停滞或排序异常。

Folo 已有 Google Developers Blog、Google AI Developers 与 Google DeepMind News，当前没有补入这个 TopHub 节点的必要。

### 6. AI 工具集

首条即为会员代充值，页面混合工具导航、商业推广与资讯。

结论：属于工具营销和转化入口，不作为信息源订阅。

### 7. CSDN 人工智能热榜

内容具有明显 SEO、批量教程、课程式标题和重复技术关键词特征，难以用热度判断质量。

用途：搜索具体实现时偶尔命中，不订阅榜单。

### 8. 产品经理的人工智能学习库

样本中既有 2025W49 周报，也有友情推广和基础入门文章，时间口径与质量不稳定。

不订阅。

### 9. 超神经

在第一页中，它较集中地覆盖 AI4Science、编译器、蛋白质设计、天气、机器人和技术教程，比纯公司快讯更接近技术纵深。

但仍混有活动宣传、招募和较旧内容。

状态：按需候选。只有当沃壤出现稳定的 AI4Science / 科研工具需求时，再检查其独立 RSS 与更新质量；当前不新增。

### AI 目录结论

- AI 目录是高重复的行业注意力层；
- 不新增量子位、AIbase、36氪 AI、AI 产品榜、CSDN AI、AI 工具集；
- Google AI Blog 当前节点疑似陈旧，不新增；
- MIT Technology Review 与超神经保留为按需候选；
- 现有 Folo 官方源与 TopHub 科技雷达已经足够。

## 最终决定

- 当前 70 个 TopHub 节点不变；
- 当前 Folo 27 个订阅不变；
- 不执行批量订阅；
- HelloGitHub：保留 TopHub 月度漫游候选，内容已验证，RSS 未验证；
- MIT Technology Review：未来官方 RSS 候选；
- 超神经：未来 AI4Science 需求出现时再审查；
- GitHub Trending、掘金、产品经理、开源中国：按需使用；
- CSDN 热榜、AI 工具集和陈旧节点：不采用。
