## 最终决定

### 新增：先知社区｜精华推荐

进入：`科技雷达`

建议位置：

- 科技雷达组内第 7；
- 放在 `The Register｜Latest` 之后；
- 放在 `科普中国网｜头条` 之前；
- 按当前 80 节点基线计算，建议全局第 25。

理由：

1. 当前科技雷达覆盖大众科技、国际科技新闻、科学、开源项目和 Apple 维修计划，但缺少稳定的应用安全、漏洞研究与 AI Agent 安全入口；
2. 先知精华同时覆盖 Web 与云安全、容器、供应链、移动应用、漏洞复现、AI 编码工具、MCP、提示注入和 Agent 工具边界；
3. 这与用户既有的网络安全硕士背景、Hack The Box、CTF、Android 逆向、Web 安全和 AI 工具安全关注直接相连；
4. “精华推荐”比普通最新流更适合作为低噪声雷达，不要求逐篇阅读；
5. 它补充 The Register 的新闻层，承担中文技术分析与实战复盘层，而不是重复一般科技媒体。

使用边界：

- 作为风险与技术变化雷达，不把每篇漏洞复现自动变成执行任务；
- 涉及真实系统时仍需确认授权、版本、影响范围和原始公告；
- 不以论坛文章替代厂商公告、CVE 记录、补丁说明和正式研究报告。

### 暂不新增：看雪论坛｜最新精华

看雪在逆向工程、内核、移动端、Hook、虚拟化和反作弊领域有独特深度，和用户过去的 Android 逆向经历高度相关。

但当前不同时加入，原因是：

- 内容明显更窄，且夹杂游戏辅助、绕过、去广告等灰度主题；
- 日常首页需要的是安全变化雷达，而不是持续深入逆向工程；
- 先知已经覆盖更广的当前安全面，先加入一个可以避免科技雷达过重；
- 当用户重新进入 Android、内核、恶意样本或深度逆向项目时，看雪可按需访问。

路由：**高价值按需来源，不进入当前 TopHub，不进入 Folo。**
