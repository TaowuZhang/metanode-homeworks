## 一、为什么不继续保留少数派｜热门文章

当前热门文章混合：

- App 推荐；
- 影视周报；
- 旅行游记；
- 编辑购物清单；
- Apple 手记；
- 数码设备；
- 系统测试版；
- 英语学习；
- 生活方式与消费内容。

它有阅读趣味，但职责已经从“科技工具入口”扩展成少数派全站生活方式精选。

主要问题：

1. 旅行、影视、购物与科技工具混在同一热榜；
2. 与 `影游音乐`、`生活与社区` 和 `慢读与思想` 的内容边界交叉；
3. 热门排序容易反复出现“本周看什么”“新玩意”“派评”等固定栏目；
4. 无法稳定补出当前科技雷达缺少的能力；
5. 现有系统已经有 IT之家、爱范儿、The Verge 等产品与设备入口，不需要再保留一个宽泛全站榜。

少数派本身仍然值得保留，但应保留它最独特的部分，而不是全站混合热榜。

## 二、为什么选择 Matrix热榜

`Matrix热榜` 当前样本包括：

- 独立开发的搜索栏工具；
- AI Markdown 编辑器；
- 专注 App；
- Coding 动画实践；
- 个人开发的 Dock；
- 生活记录 App；
- Windows 配置；
- 相机讨论；
- 语言学习；
- macOS 输入法工具；
- AI 原型迁移；
- 绿植养护小程序；
- 智能眼镜与 App 形态；
- Typora 替代品；
- UX 文件名工具；
- 消费记录产品。

它更接近少数派相对于其他科技媒体真正独特的部分：

- 独立开发者与个人工具；
- 本地软件和小型产品；
- 工作流、UX 和数字生活实践；
- 从真实需求出发的开发过程；
- 不完全依赖大公司发布与融资新闻。

### 它补出的当前缺口

当前科技雷达已经有大量：

- 大公司新闻；
- 硬件发布；
- AI产业；
- 商业与融资；
- 国际科技媒体。

相对缺少的是：

> 个人如何做工具、改造工作流、解决小问题，以及独立开发者如何把需求做成产品。

`Matrix热榜` 正好补这一层，并与 `HelloGitHub｜月刊` 形成互补：

- HelloGitHub：编辑整理的开源项目发现；
- Matrix热榜：个人工具、产品实践和开发过程。

### 保留边界

Matrix 仍是社区内容，存在：

- 自我推广；
- 产品成熟度不一；
- 标题与实际质量不完全一致；
- 少量非技术文章和生活随笔。

因此选择的是经过热度筛选的 `Matrix热榜`，不是无筛选的 `Matrix` 最新流。

它只作为 TopHub 的发现入口，不直接进入 Folo，也不把看到的每个工具都转成安装或项目任务。

## 四、少数派｜Matrix

**不新增。**

Matrix 最新流确实集中在独立应用、工作流和开发实践，但更新未经热度筛选，包含：

- 刚发布的小工具；
- 个人项目介绍；
- 产品自荐；
- 旅行和桌游文章；
- 学习方法与随笔。

相较之下，`Matrix热榜` 能减少最新流的自荐噪声，因此不同时订阅两者。

**不新增，按需观察社区问题。**

它的价值在于提出数字生活和消费技术问题，例如：

- 睡眠数据化；
- 智能家居；
- 教育优惠；
- 系统升级；
- AI 营养建议；

但它是话题与投票入口，不是稳定内容源；讨论质量、参与人数和结论都不确定。

需要观察少数派社区对某个具体问题的反应时可按需进入，不常驻。

## 七、少数派｜#派评

**不新增，作为低频 App 发现页按需使用。**

它由少数派编辑部持续整理“近期值得关注的 App”，编辑边界比全站热榜清楚，是本页质量较高的节点之一。

但它的问题是：

- 功能过窄，只承担 App 推荐；
- TopHub 列表中每期标题几乎完全相同；
- 难以仅从标题判断本期具体 App；
- 与 `#应用推荐` 及热门文章中的派评重复。

因此不作为常驻节点；当需要集中发现近期 App 时，直接打开此页。

## 八、少数派｜#应用推荐

**不新增。**

它聚合了派评、独立开发者自荐、Apple 设计奖、浏览器扩展、开源工具、知识管理与 AI 工作流等内容，题材确实贴近用户需求。

但列表过长、重复严重：

- 大量“派评”重复；
- 自荐工具质量差异大；
- 与 Matrix、Matrix热榜和少数派热门文章重合；
- 标签流没有编辑层级，容易形成 App 发现焦虑。

具体寻找 App、macOS 工具、浏览器扩展或知识管理软件时按需打开，不常驻。

## 十、少数派在系统中的正确角色

少数派不再承担：

- 全站热门生活方式榜；
- 每日科技早报；
- 付费课程上新；
- 所有 App 推荐聚合。

它保留的独特角色是：

> 独立开发者、个人工具、数字工作流与真实使用实践的社区发现入口。

因此选择 `Matrix热榜` 最符合当前七分组结构。
