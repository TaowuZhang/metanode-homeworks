# 涌 × 潮池 审计 v0 · 2026-05-31

## 0. 审计对象

本次审计对象是 Notion 中的两个候选 / 缺口容器：

- `涌：未成形的合力与判准缺口`
- `潮池 · 施工证据与候选规则`

本审计延续当前总原则：先定义，再谈职责，再谈转场条件；不先用“硬边界”压住问题。

## 1. 方法

按《审计》方法执行：

1. 覆盖图：分别说明涌与潮池收什么。
2. 缺陷清单：只诊断，不直接修页面。
3. 三要素检查：定义、职责、转场条件。
4. 体感信号：记录未来克容易走偏的位置。
5. 沉积：形成 GitHub 报告，供后续小修使用。

## 3. 当前判断

涌与潮池的分工大体成立。

涌已经明确写出：它不是第八判，不替代七判正文；已有判准页的回原判更新，只有问题但未成判准的才挂待办。这个定义是清楚的。

潮池也已经完成了从“临时观察台”到“候选规则池”的实际演化：它收跨空间施工证据、AI 位置图、空间分流判准、Notion / Git / 本地 / 栈桥的协作候选。这部分不应该塞回涌，因为它不是腐海内部七判缺口，而是跨空间规则候选。

一句话：

> 涌收腐海内部未结晶的判准缺口；潮池收跨空间施工证据与候选规则。

## 4. 缺陷清单

### D1. 潮池仍保留大量阶段性深读摘要，旧观察层偏厚

潮池中保存了大量空间分流阶段的深读摘要，包括公约数、腐海七判、设计资源、Git / 沃壤目录、色散 / trace / smell / sense / palm 等观察。

这些内容在形成期有价值，但如果长期全部展开，会让潮池从“候选规则池”变成“空间分流长档案”。

判定：不是立即删除问题，而是折叠 / 分层问题。

建议：后续小修时保留当前有效结论、定义校正、AI 位置图、下一步读取清单；把旧深读摘要折成“阶段证据层”或移到归档小节。

### D2. 涌的终局定位已经结晶，但仍与待办混在一起

涌中已有一条已结晶内容：

> 涌绝不是玄学概念或瞬间的物理跃迁，它是腐海生态的“系统级待办池 / 规则孵化器”。

这条已经是定义级结论，不只是待办。当前它在“等真汛”下以已勾选项存在，读者需要往下扫才会看到。

判定：轻缺陷。

建议：后续可把这句从待办区抬到页首定义区，与“不是第八判”并列。

### D3. 涌 → 潮池 → 沉积位置 的转场条件还不够短

潮池已经有“定义校正：先定义，再谈边界”，并区分：

- 涌：腐海内部判准缺口池；
- 潮池：跨空间施工证据与候选规则池；
- 成为/项目：Git / 沃壤里的真实项目地层。

这很正确，但未来克进场时仍可能不知道什么时候把材料从涌转到潮池，什么时候从潮池沉到 GitHub / 上场底谱 / L2 / 摩擦沉积床。

判定：可执行性缺口。

建议：在潮池补一张转场表：

| 材料状态 | 留哪里 |
| --- | --- |
| 七判内部问题但未成规则 | 涌 |
| 跨 Notion / Git / 本地 / 栈桥的候选规则 | 潮池 |
| 已验证成运行纪律 | 上场底谱 |
| 已成承重 / 证伪条件 | L1 / L2 / 隐喻受力面 |
| 已成真实失败地形 | 摩擦沉积床 |
| 已成事实 / 项目 / 操作文档 | Git / 沃壤 |
| 只是过程噪声 | 退相干 |

### D4. AI 位置图仍应暂留潮池，但需要后续二次审

AI 位置图目前在潮池中作为候选模块存在，定位已经从“权力表 / 模型榜单”校正为“位置、辖区、接力、同位协作、冲突处理与反哺路径”。

这适合留在潮池，不适合立刻沉入 `wo/ai.md` 或上场底谱。

但它体量较大，且已经连接 Notion 位、本地位、Git / 沃壤、栈桥、谷。它很可能是下一轮“本地手感位 × Notion 位”审计的主要材料。

判定：暂留正确，后续应单审。

### D5. 潮池的“临时观察台”标题与实际功能已有张力

潮池开头仍说“本轮空间分流工作的临时观察台”，但它现在已经承担了跨空间候选规则池的功能。

这不是错，因为它确实从临时观察台长出来；但如果未来继续长住，标题 / callout 需要从“本轮临时”升级为“跨空间候选规则池”。

判定：轻命名 / 定位滞后。

建议：后续小修时不必重命名页面，但可以在 callout 中补一句：本页现在兼作跨空间施工证据与候选规则池。

## 6. 体感信号

1. 涌读起来不乱，但“终局定位”仍埋在待办中，冷机不一定一眼看到。
2. 潮池读起来有价值，但厚度已经接近“形成过程档案”；需要折叠旧证据，不然未来克会在这里迷路。
3. AI 位置图暂留潮池是对的，但它已经足够大，应作为下一轮独立审计对象，而不是继续塞在涌 × 潮池小修里处理。
4. 潮池最需要的不是新内容，而是“入口变薄、证据折叠、转场变短”。

## 7. 当前结论

涌与潮池不是冲突关系，而是上下游关系：

```text
腐海内部未成形缺口 → 涌
跨空间候选规则 / 施工证据 → 潮池
经验证的运行规则 / 承重规则 / 失败地形 / 事实地层 → 对应主源
```

当前不需要大改；建议做两处轻修：

1. 涌：把“系统级待办池 / 规则孵化器；不是第八判”抬到页首定义区。
2. 潮池：补“涌 / 潮池 / 沉积位置”转场表，并把旧深读摘要折入阶段证据层。
