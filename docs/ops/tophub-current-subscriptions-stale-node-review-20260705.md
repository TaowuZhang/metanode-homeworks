# TopHub 当前订阅失效节点复核（2026-07-05）

## 触发方式

根据当前动态页中的标题、时间锚点和用户对节点实际更新情况的确认，对原有 84 个订阅进行失效节点初筛。

本轮严格区分：

- 内容本身可以是旧题材；
- 节点是否仍持续抓取新内容；
- 低频告警节点不能仅凭“没有新条目”判定失效；
- 只有标题长期停留在旧事件，且用户确认不再更新，才进入取消清单。

## 已确认失效并完成取消的四个节点

### 公共温度

1. `微信｜热词`
   - 当前标题混有冷冬、秋收等明显不合 2026 年 7 月时令的旧内容；
   - 用户确认节点不再更新；
   - 与`微信｜24h热文榜`和`今日热榜｜实时榜中榜`重复；
   - 结论：已取消，不替换。

2. `后续｜跟踪 Live`
   - 当前前列仍是养殖貂新冠、苏宁收购家乐福、黄冈卫健委、瑞幸会不会成功、波音 737 MAX 等 2019—2020 年旧事件；
   - 用户确认节点已经失效；
   - 结论：已取消，不替换。

### 生活与社区

3. `国家留学网｜综合项目专栏`
   - 当前仍以 2025、2024、2023 年项目为主，未出现 2026 年项目；
   - 用户确认节点不再更新；
   - 国家留学网本身保留为按需官网工具；
   - 结论：已取消订阅，不替换。

4. `Yoho!潮流志｜每日潮闻`
   - 当前前列仍出现 2024 年活动和旧品牌公关稿；
   - 用户确认节点不再更新；
   - 该角色也不构成当前结构中的必要缺口；
   - 结论：已取消，不替换。

## 明确保留

1. `新华每日电讯｜电子报`
   - 用户确认仍在更新；
   - 当前同时出现电子商务法修正草案、快递数据和当期世界杯等新内容；
   - 保留。

2. `喷嚏网｜乐影`
   - 用户确认仍在更新；
   - 标题中的 2020、2022、2024 多为影视作品年份，不代表节点失效；
   - 保留。

## 为什么不补位

1. 公共温度剩余 16 个节点仍足够覆盖社交热度、新闻媒体、官方叙事和全国日报；
2. 生活与社区剩余 7 个节点仍覆盖烹饪、辟谣、健康、豆瓣社区、V2EX 和旅行；
3. 为维持整数或分组数量而寻找替代，会重新制造无明确角色的订阅；
4. 先压缩到真实工作的 80 个，再继续审查其余节点，更符合“有效节点优先于总量”的原则。
